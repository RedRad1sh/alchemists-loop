# UI/UX: откат итерации-2 и новые правила приёмки (2026-10-04)

**Статус:** итерация-2 (блоки 1–5 + бэклог P2/P3, коммиты `4010036…b19fc45`)
откачена из кода игры. Оставлено только то, что прошло проверку: **сет иконок,
меню вкладок, иконки шапки (вариант A), фикс пузырька Светика**. Мок-борды

## Почему откатили

Приёмка шла по HTML/PIL-мокам (`tools/ui-preview/`), которые **не связаны с
кодом игры**: `render_shots.py` рисует картинку «из токенов». В реальной игре
попались, как минимум:

1. **Parse-ошибка в `game/home.gd:312`** — `GridContainer.new()` присваивался
   в `var _furniture_shop: VBoxContainer` (тип объявлен строкой выше). GDScript
   проверяет типы при парсинге → скрипт не компилируется, `main.gd` зовёт
   `Home.new(self)` → каскад ошибок (от «Дом сломан» до «игра не стартует»).
   CI это не ловил: Godot в CI не запускался.
2. **StyleBox на `Label` — молчаливый no-op.** У Label нет stylebox вовсе, а
   `add_theme_stylebox_override("normal", …)` тихо ничего не делает. Так были
   сделаны чипы редкости/награды в попапе, карточка «своя строка» и чип очков
   в рейтинге, чип «куплено: N» в доме, бейдж счётчика в шапке (там ещё и
   тёмный текст без фона — счётчик улучшений терялся). В моке (CSS) они
   выглядят, в игре — нет.
3. **Глобальные побочные эффекты:** `_apply_safe_area()` смешивал координаты
   дисплея (физические px, на десктопе — usable-rect экрана) с координатами
   вьюпорта 540×960 и пересчитывал отступы всего `Margin` на каждый resize;
   `UiStateTick` каждые 0.25 с перетирал `modulate` всех кнопок; fade вкладок
   запускал страницу с `alpha=0`.
4. **Несоответствие мок↔код в размерах:** `_small_button` clamp'ит высоту в
   38–42 px, поэтому заявленные в блоках 44/48 px в игре не действовали.
5. История повторяется: итерация-1 уже была откачена по той же причине
   (`f0b31fc`), итерация-2 повторила тот же цикл.

## Новые правила приёмки (обязательны для следующих итераций)

1. **Реальные кадры, а не моки.** Моки — только для согласования идеи *до*
   кода. Приёмка — по скриншотам самой игры:
   ```bash
   python3 alchemists-loop/tools/shots.py run baseline   # ДО (на этой ревизии)
   # ... правки ...
   python3 alchemists-loop/tools/shots.py run current    # ПОСЛЕ
   python3 alchemists-loop/tools/shots.py compare baseline current
   ```
   Требуется локальный Godot 4.7.x (`GODOT=/путь/к/godot`) и `xvfb-run`
   (без графической сессии). Артефакты: `previews/shots/<label>/`,
   `docs/ui-ux/shots-diff/<a>_vs_<b>/report.md`.
   **Без локальных бинарей — через CI** (джоба `ui-shots`): на каждый PR она
   снимает head и базовую ветку, кладёт `compare`-отчёт и оба набора артефактом
   `ui-shots` (retention 14 дней). Ручной запуск:
   ```bash
   gh workflow run CI.yml --ref <ветка>              # тесты + кадры
   gh workflow run CI.yml --ref <ветка> -f shots=false  # только тесты
   gh run list --workflow CI.yml --branch <ветка>     # статус
   gh run view <id> --log-failed                      # упавшие проверки
   gh run download <id> -n ui-shots                   # скачать кадры
   ```
   (Примечание: `workflow_dispatch` GitHub видит только после того, как
   `ci.yml` попадёт в `master`. До мержа агентам достаточно пуша: push в
   `arena/**` запускает `selftest` автоматически, а PR запускает
   `selftest` + `ui-shots`.)
2. **selftest на каждом PR и push.** В CI есть job `selftest`
   (Godot headless + `tools/run_selftest.sh`) — ловит parse-ошибки и регресс
   логики ещё до master; push веток `arena/**` тоже гоняет его, чтобы агенты
   проверяли себя без локального Godot.
3. **Один экран — один коммит.** Структурные правки (перестройка контейнеров)
   не пакетируются: каждый такой коммит сопровождается кадром до/после.
4. **Разделение слоёв:** скин (цвет/шрифт/радиус/иконки — через
   `DesignTokens`/`UiTheme`) меняется свободно; геометрия/структура — только
   с кадрами. StyleBox на `Label` запрещён — только `PanelContainer`-обёртка.
