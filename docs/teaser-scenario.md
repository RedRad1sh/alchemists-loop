# Тизер «Петля Алхимика» — сценарий для Shorts / TikTok

**Формат:** 9:16, 1080×1920, 30 fps, ~30 с, без озвучки (музыка + крупные субтитры в стиле TikTok).
**Стиль:** настоящие кадры игры (Godot-превью текущей сборки) + векторные SVG-оверлеи
(пар, блики, глифы, стрелки петли, финальная карточка). Палитра игры: фон `#14101c`,
бирюза `#35c4b5`, янтарь `#f5b301`, текст Manrope ExtraBold.
**Безопасные зоны:** субтитры в полосе 12–78 % высоты (не перекрываются UI Shorts/TikTok),
логотип/CTA не ниже 82 % высоты.

## Хук и драматургия

1. **0–3 с — вопрос-хук** вместо логотипа: зритель остаётся досмотреть ответ.
2. **3–10 с — ядро цикла**: тап → пара → первооткрытие. Показываем главную механику за 7 секунд.
3. **10–18 с — глубина и сердце**: коллекция + живой компаньон (эмоциональный якорь).
4. **18–26 с — мета и возврат**: дом, события, офлайн-эфир → причины вернуться завтра.
5. **26–30 с — петля и CTA**: название раскрывается в конце (мнемоника «петля»), CTA на подписку.

## Производство

- Генератор ролика: `tools/teaser/render.py` (кадры игры + SVG-оверлеи → ffmpeg, H.264+AAC).
- SVG-исходники оверлеев: `teaser/svg/*.svg` (пар и пузыри, кольцо тапа, искры, стена глифов,
  стрелки петли, финальная карточка). Рендерятся собственным растеризатором `tools/teaser/minisvg.py`
  (подмножество SVG: path/rect/circle/ellipse/line/poly, градиенты, трансформы, текст Manrope).
- Музыка и SFX: процедурные, `tools/teaser/audio.py` (numpy → WAV → AAC).
