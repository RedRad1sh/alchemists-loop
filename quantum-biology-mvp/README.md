# Quantum Biology — MVP (Godot 4.7)

Рабочий MVP кликера-эволюции из ТЗ-02: выращивание уникального существа из одной клетки.
Весь рендер существа — **кодом** (`_draw`), ни одного спрайта. Весь звук — **процедурный синтез**, ни одного аудиофайла. Сохранения — JSON в `user://`.

## Запуск

1. Установить **Godot 4.7.x** (godotengine.org).
2. Открыть в редакторе папку проекта (`project.godot`).
3. Нажать **F5** (или ▶). Готово.

Управление: тап по пузырькам = энергия (работает и тачем на Android, и мышью на ПК); тап по существу = погладить; кнопка **ДЕЛЕНИЕ** = эволюция и выбор гена; кнопка **Геном** = перестановка генов (порядок меняет вид!); тап по ДНК-коду = копировать.

## Что внутри (петля MVP)

- **Клетка → существо:** каждое «деление» даёт выбор 1 из 3 генов (редкости: обычный/редкий/эпический/легендарный, легендарный «Квантовая аура» требует «Биолюминесценцию»).
- **Порядок генов влияет:** гены применяются последовательно, соседние пары дают эпистаз-бонусы («Гигантизм + Хитиновый панцирь» = бронированный гигант). Переставляй в «Геноме» — существо мутирует на глазах.
- **Стадии:** Прокариота → Колония → Жгутиконосец → … → Квантовая жизнь (по числу делений).
- **Оффлайн-споры:** пассивный доход за время отсутствия (кап 8 ч) с тостом при возврате.
- **Код ДНК:** детерминированная подпись генома (`QB-…`), копируется в буфер (база для будущего «Музея» и обмена).
- Автосейв каждые 15 с + при сворачивании; миграция/защита битого сейва.
- RU/EN локализация (по языку ОС), Noto Sans (кириллица), вибрация, музыка-эмбиент с выключателем.

## Структура

```
autoload/
  event_bus.gd      # шина событий
  i18n.gd           # локализация (t()/tf(); tr зарезервирован Object)
  sfx.gd            # процедурные SFX + музыка (синтез в WAV на лету)
  game_state.gd     # энергия, деления, геном, драбл-кандидаты, сейвы, ДНК-код
game/
  phenotype_engine.gd  # ЧИСТЫЙ детерминированный движок: геном -> фенотип (без UI)
  creature_visual.gd   # рендер существа кодом: морф, волна, глаза, шипы, свечение
  dish.gd              # чашка Петри: фон, пузырьки-еда, тапы (мультитач), флоатеры
scenes/
  main.gd / main.tscn  # HUD, оверлеи, поток игры, selftest
  draft_overlay.gd     # «Выбери ген» (1 из 3)
  genome_overlay.gd    # перестановка генов, ДНК-код
data/
  genes.json           # 11 генов: редкость, требования, пассив, имена ru/en
  i18n.json
previews/              # скриншоты разных существ (сняты в игре)
```

## Автотесты (headless)

```bash
godot --headless --path . -- --selftest
# ожидаем: SELFTEST PASS (19/19)
```

Проверяют: локализацию, данные, детерминизм фенотипа, «порядок влияет» (эпистаз), стадии,
экономику, уникальность ДНК-кода, доступность легендарного гена (детерминированно, по пулу),
открытие UI-оверлеев, цикл деления, **перемешивание генома**, **тап по пузырьку даёт энергию /
тап по пустому месту — нет**, roundtrip сейва. Прогон в CI — ~1 с.

## Графика: из чего состоит (v2, «графический пасс»)

- **Фон — шейдер каустик** (`assets/shaders/dish_bg.gdshader`): живая «вода» из sin-волн + верхний свет + виньетка + зерно. Ноль текстур, анимация бесплатно.
- **Стеклянный декор** (`game/dish_deco.gd`): дуги-блики чашки, мягкие «боке» в толще воды.
- **Существо — «желе»**: мягкие радиальные градиенты (`game/art.gd`, кэш `GradientTexture2D`) вместо плоских кругов: ореол → тело → внутренняя тень → влажный блик. Глаза со свечением, мягкие тени на «дне».
- **Пузырьки**: ореол + ядро + нижняя тень + блик, «дыхание».
- **Иконки генов** — процедурный «неон»-генератор (`tools/gen_gene_icons.py`): чёткие символы (молния, лист, глаз, щит, корона…), цвет по смыслу, свечение. Понятно без подписи, в отличие от первой версии (ИИ-генерация) — её результат сохранён в `assets/ai_art/` как пример «как не надо».
- **UI**: «попап» счётчика энергии (tween scale), пульсация кнопки «ДЕЛЕНИЕ» при достатке, приглушение при нехватке.
- **Стадии выглядят по-разному**: фон-«среда» меняется со стадией (глубоководье → лагуна → золото → фиолет); визуальные вехи: колония-почкование (ст.1+), усики (ст.3+), полосы-узор, хитиновые пластины и янтарные шипы, золотое кольцо-«венец» (ст.6), вторая орбита + фиолетовая аура с лучами (ст.7).
- Полная линейка: `previews/evolution_v3.png` (8 стадий) и `previews/stage_0..7.png`.

## Экспорт на Android (кратко)

1. Редактор → Project → Export → Add… → **Android**.
2. **Install Android Build Template** (в окне экспорта) — понадобится JDK 17 и Android SDK.
3. Пресет: `Min SDK 24`, `Target SDK 36`, архитектура arm64-v8a (или обе ARM), графика Compatibility.
4. Release: заполнить Keystore (создать свой! хранить в двух местах) → Export Project → **AAB** для Google Play / APK для RuStore.
5. Ориентация портрет уже задана в `project.godot`.

## Известные рамки MVP (сознательно вне скоупа)

- Нет «Живого музея», обмена ДНК-кодами между игроками и превью-«призрака» мутаций — это v1.1 (каркас заложен: код ДНК, геном-как-данные).
- Нет сред и «приспособленности» (среда давит) — следующий шаг по ТЗ.
- Нет мутаций-дрейфа, «Пересева» (престижа) и 2–3 чашек.
- Драбл без реролла (монетизация rewarded — на этапе подключения рекламы).
- Баланс стартовый, калибруется симулятором `tools/balance_sim`.

Следующие шаги по роадмапу ТЗ-02 (неделя 4+): среды с fitness → карточка-шеринг PNG (SubViewport) → музей с ДНК-кодами → «Пересев».
