# Пакет ТЗ: три Android-игры на Godot 4

Полный комплект технических заданий и инструкций по разработке, монетизации и публикации трёх игр:

| # | Игра | Жанр | Киллер-фича | Документ |
|---|------|------|-------------|----------|
| 1 | **ALCHEMIST'S LOOP** | кликер-алхимия + крафт | «Случайные открытия»: первое в мире открытие вещества, автор даёт ему имя, вещество появляется у всех | `01-alchemists-loop.md` |
| 2 | **Quantum Biology** | кликер-эволюция/тамагочи | процедурный вид существа, зависящий от порядка купленных генов; нет двух одинаковых | `02-quantum-biology.md` |
| 3 | **LAUNCH DAY** | кликер-тайкун космоса | запуски в реальном времени + альянсы и «Космическая гонка» | `03-launch-day.md` |

**Общие документы (на них ссылаются все три ТЗ):**

- `00-godot-android-skeleton.md` — общий скелет проекта на Godot 4.7 для Android: структура, autoload-синглтоны, сохранения, жизненный цикл ОС, перфоманс, аудио-инфраструктура и процедурная генерация музыки, стандарты аналитики, CI.
- `04-monetization-and-publishing.md` — общая процедура монетизации и публикации: плагины платежей (Google Play Billing / RuStore Pay), рекламные сети, требования и пошаговые чек-листы Google Play и RuStore, юридический минимум.

## Ключевые решения, принятые в пакете (актуально на сентябрь 2026)

| Вопрос | Решение | Обоснование |
|---|---|---|
| Движок | Godot **4.7.2** stable, GDScript | актуальный стабильный релиз (авг. 2026), стабильный Android-экспорт, 16 КБ-выравнивание из коробки |
| Рендерер | **Compatibility** (OpenGL ES) | игры 2D; ниже нагрев/расход батареи, работает на слабых устройствах, меньше размер AAB |
| Язык кода | GDScript; C#/Kotlin только для плагинов | скорость итераций; нативный код — только там, где без него нельзя (реклама, платежи) |
| Хранилище | 3 отдельных проекта в монорепо + общий код | независимые релизы, разный серверный бэкенд, общий слой вынесен в `common/` |
| Сохранения | JSON в `user://`, атомарная запись, версионирование, миграции | простота, надёжность; шифрование не даёт защиты от читеров, поэтому не используем |
| Монетизация RU | Яндекс Mobile Ads (rewarded/interstitial) + IAP через RuStore Pay | для РФ; реклама работает и для физлиц (платежи RuStore — только для ИП/юрлиц с 01.02.2026) |
| Монетизация GP | AdMob + официальный GodotGooglePlayBilling | глобальный билд; Google Play Billing официальный плагин godotengine |
| Аналитика | GameAnalytics (официальный Godot SDK 3.x, MIT) | бесплатно, простой SDK, нет привязки к Google |
| Публикация | Google Play (targetSdk 36, 16 КБ) + RuStore (APK/AAB) | оба стора; учитываем закрытое тестирование 12×14 дней для новых личных аккаунтов GP |
| Целевые устройства | Android 7.0+ (minSdk 24), эталон слабого устройства — Redmi-класс (Adreno 6xx, 2 ГБ RAM) | покрывает ~95%+ активных устройств обеих площадок |

## Порядок чтения и работы

1. Прочитать `00` — общий скелет (обязателен для всех трёх игр, экономит ~40% работы за счёт переиспользования).
2. Взять ТЗ игры (`01`→`02`→`03`) — они самодостаточны: каждая содержит свою аналитику, графику, аудио, монетизацию, тестирование и публикацию.
3. Перед релизом — `04`: подключение платежей/рекламы и чек-листы площадок.

Рекомендуемый порядок производства: **Quantum Biology** (самая дешёвая MVP-проверка виральности) → **ALCHEMIST'S LOOP** (флагман с мета-слоем) → **LAUNCH DAY** (самый сложный, требует сервер реального времени и аудиторию). Подробные оценки трудозатрат — в разделе «Дополнительно» каждого ТЗ.

## Структура типового ТЗ (одинаковая для всех трёх игр)

1. Концепт, аудитория, УТП
2. Core loop и игровые механики (спецификация + балансовые формулы)
3. Прогрессия, ретеншн, мета-слой
4. Аналитика: события, воронки, KPI, A/B-гипотезы
5. Скелет Godot: сцены, синглтоны, данные, ключевой код
6. UX и user-friendly геймплей
7. Графика упрощённым путём (процедурно + API + CC0)
8. Аудио: генерация саундтрека «под вайб» + звуковой дизайн
9. Монетизация
10. Тестирование
11. Публикация в Google Play и RuStore
12. Дополнительные разделы: риски, роадмап, оценки трудозатрат, юридика

> **Пометка о статусах:** в текстах встречаются решения, помеченные как *«открытый вопрос»* или *«калибруется плейтестом»* — это осознанно: точные числа баланса и пороги показываются в плейтестах, в ТЗ зафиксированы стартовые значения и методика калибровки.

## Сверка с альтернативным ТЗ (сравнение версий, сентябрь 2026)

Пакет сверялся с независимым ТЗ («Claude fable 5.1 search»). Итог сверки:

**Почему «сложности получились наоборот» — разница скоупа, а не оценки:**

| | Альтернативное ТЗ (локальный скоуп) | Этот пакет (полный бриф заказчика) |
|---|---|---|
| ALCHEMIST'S LOOP | скрытые рецепты **офлайн**, сюжетная петля-престиж | + **серверная мировая мета**: «случайные открытия» с протоколом первооткрытия, живой пул, таблица сообщества |
| Quantum Biology | процедурный визуал из ~40 модульных спрайтов | процедурный рендер **кодом** (`_draw`), сервер не нужен |
| LAUNCH DAY | QTE-запуски, локальные таймеры, детерминированный «нарратив дня» без сервера | + **real-time окна на сервере**, presence, альянсы, «Космическая гонка» |

Отсюда: у них Launch Day — самый дешёвый (8–10 нед.), Quantum Biology — самый дорогой (10–12 нед.); здесь — Quantum Biology самый дешёвый (1.5–2 чел. × 8 нед.), Launch Day в полном брифе самый дорогой (2–2.5 чел. × 10 нед. + сервер). **Обе оценки корректны для своего скоупа**; при сведении к общему знаменателю (локальные версии) порядок у нас сходится с альтернативой: Launch Day ≈ Quantum Biology ≈ Alchemist, Launch Day — быстрейший MVP без сервера. В ТЗ-03 и ТЗ-02 добавлены явные «варианты скоупа» с оценками, чтобы цифры нельзя было прочитать превратно.

**Заимствовано из альтернативного ТЗ после проверки** (внесено в документы):
- Godot 4.6+ зеркалирование Android-устройств в редакторе (проверено: godotengine.org, апрель 2026) — в чек-лист тестирования доки 00.
- Нативные `AudioStreamInteractive` / `AudioStreamSynchronized` / `AudioStreamPlaylist` (Godot 4.3+, проверено: официальные release notes) — в аудио-раздел доки 00.
- QTE-фаза «удержание в зелёной зоне + развилки» в окно запуска Launch Day, шанс успеха в диапазоне [0.05; 0.97] «никогда не 100%», автопилот для idle-игроков, pity-бонус после 3 провалов.
- «Среда давит» (приспособленность к среде с видимой причиной), превью-«призрак» мутаций, процедурный «голос» существа — в Quantum Biology.
- BigNum, единый тик-таймер, мультитач через InputEventScreenTouch, StyleBoxFlat-UI, палитры Lospec, аватар-API (DiceBear), jsfxr/BeepBox — в общий фундамент (дока 00).
- Риск «стоимость личного контента» в мировой мете Alchemist (бесплатные попытки «тумана» — чтобы гонка не превращалась в аукцион).

**Отклонено осознанно:** «Mobile renderer» вместо Compatibility (в Godot 4.7 для чистых 2D-игр Compatibility — официальная рекомендация: ниже расход батареи, шире парк GPU; Vulkan Mobile не даёт нам ничего нужного); рендер существа набором спрайтов (вместо `_draw` — см. выше); кнопки-«магниты» UI на игровом поле (заменено InputEventScreenTouch); урезание real-time/мировой меты из ТЗ-01/03 (это и есть киллер-фичи брифа — предложены как варианты скоупа, а не замена).
