Ниже — готовый модуль `alchemy_llm.py`, реализующий все предложения из разбора. Что вошло:

- **БД решений** (SQLite, легко заменить на Postgres): `accepted / rejected / needs_review` + провенанс (источник, модель, версия промпта, попытки).
- **Трёхступенчатый конвейер**: генератор (только смысл, строгий промпт) → независимый судья → классификатор category/glyph с правило-фоллбэком.
- **Технический сбой ≠ «не сочетается»**: `LLMError` возвращает `status="error"` и ничего не пишет в БД.
- **Никакого хардкода запретов в рантайме**: ручные решения — через admin-API в БД; старый список оставлен только как разовая миграция.
- **Фидбек-луп**: отклонённый судьёй кандидат возвращается генератору как подсказка (до `LLM_MAX_CANDIDATES` попыток), затем `needs_review`.
- **Ротация только как failover** по техническим ошибкам; отдельная модель судьи (`LLM_JUDGE_MODEL`).
- Исправлены: приоритет ключей (OpenRouter-ключ не утекает к другим провайдерам), работа без ключа (Ollama), авто-фоллбэк `response_format`, корректный парсинг JSON (баланс скобок, а не жадная регулярка), `temperature` 0.2/0.0, адекватный `max_tokens`.

def pair_key(a_id: str, b_id: str) -> str:
    """Канонический ключ пары: порядок ингредиентов не важен."""
    x, y = str(a_id), str(b_id)
    return f"{x}|{y}" if x <= y else f"{y}|{x}"

_NAME_RE = re.compile(r"[А-Яа-яЁё]+(?: [А-Яа-яЁё]+)*")


def normalize_name(raw) -> str | None:
    """Нормализация/валидация имени результата. None — невалидно."""
    s = " ".join(str(raw or "").split())
    if not s or len(s) > 40:
        return None
    if not _NAME_RE.fullmatch(s):  # только кириллица и одинарные пробелы
        return None
    return s[0].upper() + s[1:]


def extract_json_object(text: str) -> dict | None:
    """Достать ПЕРВЫЙ корректный JSON-объект из ответа модели.

    Устойчив к ```-обёрткам и тексту до/после JSON. В отличие от жадной
    регулярки, не ломается на двух объектах в ответе.
    """
    if not text:
        return None
    text = text.strip()
    if text.startswith("```"):
        text = re.sub(r"^```[a-zA-Z]*\s*", "", text)
        text = re.sub(r"\s*```$", "", text).strip()
    start = text.find("{")
    if start == -1:
        return None
    depth, in_str, esc = 0, False, False
    for i in range(start, len(text)):
        ch = text[i]
        if in_str:
            if esc:
                esc = False
            elif ch == "\\":
                esc = True
            elif ch == '"':
                in_str = False
        elif ch == '"':
            in_str = True
        elif ch == "{":
            depth += 1
        elif ch == "}":
            depth -= 1
            if depth == 0:
                try:
                    return json.loads(text[start:i + 1])
                except json.JSONDecodeError:
                    return None
    return None

class SQLiteStore:
    def __init__(self, path: str = "alchemy.db"):
        self._lock = threading.Lock()
        self._db = sqlite3.connect(path, check_same_thread=False)
        self._db.execute("""
            CREATE TABLE IF NOT EXISTS combinations (
                pair_key       TEXT PRIMARY KEY,
                a_id           TEXT NOT NULL,
                b_id           TEXT NOT NULL,
                status         TEXT NOT NULL
                    CHECK (status IN ('accepted','rejected','needs_review')),
                element_json   TEXT,
                reason         TEXT,
                source         TEXT NOT NULL,
                model          TEXT,
                judge_model    TEXT,
                prompt_version TEXT,
                attempts       INTEGER DEFAULT 0,
                notes          TEXT,
                updated_at     TEXT NOT NULL
            )
        """)
        self._db.commit()

    _COLS = ("pair_key,a_id,b_id,status,element_json,reason,source,"
             "model,judge_model,prompt_version,attempts,notes,updated_at")

    def get(self, key: str) -> StoredDecision | None:
        with self._lock:
            row = self._db.execute(
                f"SELECT {self._COLS} FROM combinations WHERE pair_key=?", (key,)
            ).fetchone()
        if not row:
            return None
        return StoredDecision(
            pair_key=row[0], a_id=row[1], b_id=row[2], status=row[3],
            element=json.loads(row[4]) if row[4] else None,
            reason=row[5] or "", source=row[6] or "llm",
            model=row[7] or "", judge_model=row[8] or "",
            prompt_version=row[9] or "", attempts=row[10] or 0,
            notes=row[11] or "", updated_at=row[12] or "",
        )

    def put(self, d: StoredDecision) -> None:
        now = datetime.now(timezone.utc).isoformat(timespec="seconds")
        with self._lock:
            self._db.execute(
                """INSERT INTO combinations
                       (pair_key,a_id,b_id,status,element_json,reason,source,
                        model,judge_model,prompt_version,attempts,notes,updated_at)
                   VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?)
                   ON CONFLICT(pair_key) DO UPDATE SET
                       status=excluded.status, element_json=excluded.element_json,
                       reason=excluded.reason, source=excluded.source,
                       model=excluded.model, judge_model=excluded.judge_model,
                       prompt_version=excluded.prompt_version,
                       attempts=excluded.attempts, notes=excluded.notes,
                       updated_at=excluded.updated_at""",
                (d.pair_key, d.a_id, d.b_id, d.status,
                 json.dumps(d.element, ensure_ascii=False) if d.element else None,
                 d.reason, d.source, d.model, d.judge_model, d.prompt_version,
                 d.attempts, d.notes, now),
            )
            self._db.commit()

    def close(self) -> None:
        self._db.close()

@dataclass
class Config:
    provider: str = "off"            # openrouter | openai_compatible | mock | off
    api_key: str = ""
    base_url: str = ""
    models: list = field(default_factory=list)          # [основная, failover...]
    judge_models: list = field(default_factory=list)    # отдельная модель судьи
    timeout: float = 30.0
    max_candidates: int = 3          # попыток генератора до needs_review
    gen_temperature: float = 0.2
    judge_temperature: float = 0.0
    judge_min_score: float = 0.6     # доп. проверка оценок судьи в коде
    db_path: str = "alchemy.db"
    log_raw: bool = False
    json_mode: bool = True           # LLM_JSON_MODE=off, если провайдер не умеет

    @classmethod
    def from_env(cls) -> "Config":
        provider = os.environ.get("LLM_PROVIDER", "off").strip().lower()
        raw = os.environ.get("LLM_MODELS", DEFAULT_MODELS)
        models = [m.strip() for m in raw.split(",") if m.strip()]
        judge_raw = os.environ.get("LLM_JUDGE_MODEL", "").strip()
        if judge_raw:
            judge_models = [judge_raw] + [m for m in models if m != judge_raw]
        else:
            judge_models = list(models)
        # Ключи строго по провайдеру: OpenRouter-ключ не уходит на чужой эндпоинт.
        api_key = ""
        if provider == "openrouter":
            api_key = os.environ.get("OPENROUTER_API_KEY", "")
        elif provider == "openai_compatible":
            api_key = os.environ.get("LLM_API_KEY", "")  # опционален (Ollama)
        return cls(
            provider=provider,
            api_key=api_key,
            base_url=os.environ.get("LLM_BASE_URL", "").strip(),
            models=models,
            judge_models=judge_models,
            timeout=float(os.environ.get("LLM_TIMEOUT", "30")),
            max_candidates=max(1, int(os.environ.get("LLM_MAX_CANDIDATES", "3"))),
            gen_temperature=float(os.environ.get("LLM_GEN_TEMPERATURE", "0.2")),
            judge_temperature=float(os.environ.get("LLM_JUDGE_TEMPERATURE", "0.0")),
            judge_min_score=float(os.environ.get("LLM_JUDGE_MIN_SCORE", "0.6")),
            db_path=os.environ.get("ALCHEMY_DB_PATH", "alchemy.db"),
            log_raw=os.environ.get("ALCHEMY_LOG_RAW", "0").lower() in ("1", "true", "yes"),
            json_mode=os.environ.get("LLM_JSON_MODE", "on").strip().lower()
                      not in ("off", "0", "false"),
        )


class ChatClient:
    """Низкоуровневый чат-клиент. Возвращает (content, model).

    Failover: при технической ошибке (сеть, 429, 5xx) берётся следующая
    модель из списка. Семантических решений здесь нет — только транспорт.
    """

    def __init__(self, cfg: Config):
        self.cfg = cfg

    def chat(self, *, messages: list, models: list | None = None,
             temperature: float = 0.0, max_tokens: int = 200,
             tag: str = "llm") -> tuple[str, str]:
        models = models or self.cfg.models
        if not models:
            raise LLMError("не настроено ни одной модели (LLM_MODELS)")
        errors: list[str] = []
        for model in models:
            try:
                return self._chat_one(model, messages, temperature, max_tokens, tag)
            except LLMError as e:
                errors.append(f"{model}: {e}")
                log.warning("[%s] failover: %s", tag, errors[-1])
        raise LLMError("все модели недоступны: " + "; ".join(errors))

    def _chat_one(self, model, messages, temperature, max_tokens, tag):
        url, headers = self._endpoint()
        use_rf = self.cfg.json_mode
        for _ in range(2):
            payload = {"model": model, "messages": messages,
                       "temperature": temperature, "max_tokens": max_tokens}
            if use_rf:
                payload["response_format"] = {"type": "json_object"}
            try:
                r = requests.post(url, json=payload, headers=headers,
                                  timeout=self.cfg.timeout)
            except requests.RequestException as e:
                raise LLMError(f"сеть: {e.__class__.__name__}") from e
            if r.status_code == 200:
                try:
                    content = r.json()["choices"][0]["message"]["content"] or ""
                except (KeyError, IndexError, ValueError) as e:
                    raise LLMError("неожиданный формат ответа") from e
                if not content.strip():
                    raise LLMError("пустой ответ модели")
                if self.cfg.log_raw:
                    log.debug("[%s][%s] raw: %s", tag, model, content)
                return content, model
            body = r.text[:300].replace("\n", " ")
            # некоторые провайдеры не поддерживают response_format —
            # повторяем тот же запрос без него
            if r.status_code == 400 and use_rf and "response_format" in body:
                use_rf = False
                continue
            raise LLMError(f"HTTP {r.status_code}: {body}")
        raise LLMError("провайдер отклонил запрос (response_format?)")

    def _endpoint(self) -> tuple[str, dict]:
        if self.cfg.provider == "openrouter":
            if not self.cfg.api_key:
                raise LLMError("нет ключа OPENROUTER_API_KEY")
            headers = {
                "Authorization": f"Bearer {self.cfg.api_key}",
                "Content-Type": "application/json",
                "HTTP-Referer": os.environ.get("LLM_HTTP_REFERER", "https://localhost"),
                "X-Title": "Alchemist Loop",
            }
            return OPENROUTER_URL, headers
        # openai_compatible: ключ опционален (локальный Ollama работает без него)
        base = (self.cfg.base_url or "").rstrip("/")
        if not base:
            raise LLMError("для openai_compatible нужен LLM_BASE_URL")
        if base.endswith("/chat/completions"):
            url = base
        elif re.search(r"/v\d+$", base):
            url = base + "/chat/completions"
        else:
            url = base + "/v1/chat/completions"
        headers = {"Content-Type": "application/json"}
        if self.cfg.api_key:
            headers["Authorization"] = f"Bearer {self.cfg.api_key}"
        return url, headers

def _generator_user_prompt(a: ElementRef, b: ElementRef, hint: str | None) -> str:
    parts = []
    if a.id == b.id:
        parts.append(f"ВНИМАНИЕ: оба слота — один и тот же элемент «{a.name}» "
                     "(две независимые копии).")
    parts.append(f"Понятие A: «{a.name}» — {a.description or 'описания нет'} "
                 f"(категория: {a.category or '—'}).")
    parts.append(f"Понятие B: «{b.name}» — {b.description or 'описания нет'} "
                 f"(категория: {b.category or '—'}).")
    if hint:
        parts.append("Уточнение: " + hint)
    parts.append("Верни строго один JSON-объект по формату из системного промпта.")
    return "\n".join(parts)


def _judge_user_prompt(a: ElementRef, b: ElementRef, cand: Candidate) -> str:
    return (f"A: «{a.name}» — {a.description or '—'}\n"
            f"B: «{b.name}» — {b.description or '—'}\n"
            f"Предложенный результат C: «{cand.name}» — {cand.description or '—'}\n"
            f"Обоснование генератора: {cand.reason or '—'}")


def _rejection_user_prompt(a: ElementRef, b: ElementRef, reason: str) -> str:
    return (f"A: «{a.name}» — {a.description or '—'}\n"
            f"B: «{b.name}» — {b.description or '—'}\n"
            f"Решение генератора: прямого результата нет. "
            f"Обоснование: {reason or 'не указано'}")


def _parse_proposal(res) -> Proposal | None:
    if not isinstance(res, dict):
        return None
    if res.get("combinable") is False:
        return Proposal(True, reason=str(res.get("reason", ""))[:200])
    if res.get("combinable") is not True:
        return None
    name = normalize_name(res.get("name"))
    if name is None:
        return None
    desc = " ".join(str(res.get("description", "")).split())[:200]
    mech = str(res.get("mechanism", "other")).strip().lower()
    if mech not in MECHANISMS:
        mech = "other"
    reason = str(res.get("reason", "")).strip()[:300]
    return Proposal(False, Candidate(name, desc, mech, reason), reason)


class Generator:
    """Шаг 1: смысл и имя. Glyph/category здесь НЕТ — их выбирает классификатор."""

    def __init__(self, client: ChatClient, cfg: Config):
        self.client, self.cfg = client, cfg

    def propose(self, a: ElementRef, b: ElementRef,
                hint: str | None = None) -> tuple[Proposal, str]:
        messages = [
            {"role": "system", "content": GENERATOR_SYSTEM_PROMPT},
            {"role": "user", "content": _generator_user_prompt(a, b, hint)},
        ]
        last = ""
        for attempt in (1, 2):  # вторая попытка — только на битый формат
            content, model = self.client.chat(
                messages=messages, models=self.cfg.models,
                temperature=self.cfg.gen_temperature,
                max_tokens=220, tag="gen")
            last = content
            p = _parse_proposal(extract_json_object(content))
            if p is not None:
                return p, model
            if attempt == 1:
                messages.append({"role": "user", "content":
                    "Ответ не по формату. Верни СТРОГО один JSON: "
                    '{"combinable": true, "name": "Имя", "description": "...", '
                    '"mechanism": "construction|group|mixture|interaction|other", '
                    '"reason": "..."} или {"combinable": false, "reason": "..."}.'})
        raise LLMError(f"генератор: невалидный ответ: {last[:160]}")


class Judge:
    """Шаг 2: независимая семантическая проверка."""

    def __init__(self, client: ChatClient, cfg: Config):
        self.client, self.cfg = client, cfg

    def evaluate(self, a: ElementRef, b: ElementRef,
                 cand: Candidate) -> tuple[Verdict, str]:
        messages = [
            {"role": "system", "content": JUDGE_SYSTEM_PROMPT},
            {"role": "user", "content": _judge_user_prompt(a, b, cand)},
        ]
        for attempt in (1, 2):
            content, model = self.client.chat(
                messages=messages, models=self.cfg.judge_models,
                temperature=self.cfg.judge_temperature,
                max_tokens=150, tag="judge")
            v = self._parse_verdict(extract_json_object(content))
            if v is not None:
                # страховка от «добрых» судей: если модель вернула valid=true,
                # но сама же поставила кому-то низкую оценку — отклоняем
                if v.scores:
                    v.valid = v.valid and min(v.scores.values()) >= self.cfg.judge_min_score
                return v, model
            if attempt == 1:
                messages.append({"role": "user", "content":
                    "Ответ не по формату. Верни строго JSON: "
                    '{"valid": true|false, "scores": {"uses_both": 0.0, '
                    '"directness": 0.0, "commonness": 0.0, "naming": 0.0}, '
                    '"reason": "..."}'})
        raise LLMError("судья: невалидный ответ")

    def confirm_rejection(self, a: ElementRef, b: ElementRef,
                          reason: str) -> tuple[RejectionCheck, str]:
        """Проверка отказа генератора: судья может не согласиться и
        предложить свой кандидат."""
        messages = [
            {"role": "system", "content": REJECTION_SYSTEM_PROMPT},
            {"role": "user", "content": _rejection_user_prompt(a, b, reason)},
        ]
        for attempt in (1, 2):
            content, model = self.client.chat(
                messages=messages, models=self.cfg.judge_models,
                temperature=self.cfg.judge_temperature,
                max_tokens=150, tag="judge-rej")
            chk = self._parse_rejection(extract_json_object(content))
            if chk is not None:
                return chk, model
            if attempt == 1:
                messages.append({"role": "user", "content":
                    "Ответ не по формату. Верни строго JSON: "
                    '{"rejected": true, "reason": "..."} или '
                    '{"rejected": false, "candidate": {"name": "...", '
                    '"description": "...", "reason": "..."}, "reason": "..."}'})
        raise LLMError("судья (проверка отказа): невалидный ответ")

    @staticmethod
    def _parse_verdict(res) -> Verdict | None:
        if not isinstance(res, dict):
            return None
        valid = res.get("valid")
        if not isinstance(valid, bool):
            return None
        scores = {}
        raw = res.get("scores")
        if isinstance(raw, dict):
            for k in ("uses_both", "directness", "commonness", "naming"):
                v = raw.get(k)
                if isinstance(v, (int, float)):
                    scores[k] = max(0.0, min(1.0, float(v)))
        return Verdict(valid, scores, str(res.get("reason", ""))[:300])

    @staticmethod
    def _parse_rejection(res) -> RejectionCheck | None:
        if not isinstance(res, dict):
            return None
        rej = res.get("rejected")
        if not isinstance(rej, bool):
            return None
        cand = None
        raw_c = res.get("candidate")
        if isinstance(raw_c, dict):
            name = normalize_name(raw_c.get("name"))
            if name:
                cand = Candidate(
                    name,
                    " ".join(str(raw_c.get("description", "")).split())[:200],
                    "other",
                    str(raw_c.get("reason", ""))[:300],
                )
        return RejectionCheck(rej, str(res.get("reason", ""))[:300], cand)


class Classifier:
    """Шаг 3: категория + глиф. Сбой классификатора НЕ бракует результат —
    включается правило-фоллбэк."""

    def __init__(self, client: ChatClient, cfg: Config):
        self.client, self.cfg = client, cfg

    def classify(self, name: str, description: str = "") -> tuple[str, str, str]:
        try:
            return self._llm(name, description)
        except LLMError as e:
            log.warning("классификатор недоступен (%s), использую правила", e)
            cat, glyph = self.rule_classify(name, description)
            return cat, glyph, "rules"

    def _llm(self, name, description):
        messages = [
            {"role": "system", "content": CLASSIFIER_SYSTEM_PROMPT},
            {"role": "user", "content":
                f"Имя элемента: «{name}»\nОписание: {description or '—'}"},
        ]
        for attempt in (1, 2):
            content, model = self.client.chat(
                messages=messages, models=self.cfg.models,
                temperature=0.0, max_tokens=40, tag="cls")
            res = extract_json_object(content)
            if isinstance(res, dict):
                category = str(res.get("category", "")).strip().lower()
                glyph = str(res.get("glyph", "")).strip().lower()
                if category in CATEGORIES:
                    if glyph in GLYPHS:
                        return category, glyph, model
                    return category, GLYPH_BY_CATEGORY[category], model
            if attempt == 1:
                messages.append({"role": "user", "content":
                    "Ответ не по формату. Верни строго JSON: "
                    '{"category": "огонь|вода|земля|воздух", "glyph": "<ключ из списка>}'})
        raise LLMError("классификатор: невалидный ответ")

    @staticmethod
    def rule_classify(name: str, description: str = "") -> tuple[str, str]:
        low = (name + " " + (description or "")).lower()
        for key, glyph in _NAME_GLYPH_HINTS:
            if key in low:
                return GLYPH_TO_CATEGORY.get(glyph, "земля"), glyph
        return "земля", "stone"

class MockBackend:
    """Детерминированная заглушка. Для своих сценариев передайте reject/recipes."""

    def __init__(self, reject: Iterable[str] = (), recipes: dict | None = None):
        self.reject = set(reject)             # канонические pair_key
        self.recipes = dict(recipes or {})    # pair_key -> Candidate

    def propose(self, a: ElementRef, b: ElementRef,
                hint: str | None = None) -> tuple[Proposal, str]:
        key = pair_key(a.id, b.id)
        if key in self.reject:
            return Proposal(True, reason="mock: пара в тестовом reject-списке"), "mock"
        cand = self.recipes.get(key)
        if cand is None:
            first, second = (a, b) if a.id <= b.id else (b, a)
            cand = Candidate(first.name + " " + second.name, "mock-склейка",
                             "other", "mock")
        return Proposal(False, cand, ""), "mock"

class AlchemyService:
    def __init__(self, cfg: Config, store: SQLiteStore | None = None,
                 mock_backend: MockBackend | None = None):
        self.cfg = cfg
        self.store = store or SQLiteStore(cfg.db_path)
        self.client = ChatClient(cfg)
        self.generator = Generator(self.client, cfg)
        self.judge = Judge(self.client, cfg)
        self.classifier = Classifier(self.client, cfg)
        self.mock = mock_backend or MockBackend()

    # ------------------------------------------------------------------ API

    def available(self) -> bool:
        if self.cfg.provider in ("", "off"):
            return False
        if self.cfg.provider == "mock":
            return True
        if not self.cfg.models:
            return False
        if self.cfg.provider == "openrouter":
            return bool(self.cfg.api_key)
        return True  # openai_compatible может работать без ключа (Ollama)

    def resolve(self, a: ElementRef, b: ElementRef) -> Outcome:
        """Главный метод. См. docstring Outcome про трактовку статусов."""
        key = pair_key(a.id, b.id)
        cached = self.store.get(key)
        if cached:
            if cached.status == "accepted":
                return Outcome("accepted", element=cached.element, source="db",
                               model=cached.model, judge_model=cached.judge_model,
                               detail=cached.reason)
            if cached.status == "rejected":
                return Outcome("rejected", source="db", detail=cached.reason)
            # needs_review — ниже перегенерируем с подсказкой
        if self.cfg.provider == "off":
            return Outcome("error", detail="LLM выключен, решения в БД нет")
        if self.cfg.provider == "mock":
            return self._mock_resolve(a, b)
        return self._llm_resolve(a, b, key, cached)

    def generate_compat(self, a_slug, b_slug, a_name, b_name, a_cat, b_cat,
                        a_desc: str = "", b_desc: str = "") -> dict:
        """Обёртка совместимости со старым API generate().
        ВАЖНО: error пробрасывается исключением LLMError — технический сбой
        по-прежнему НЕ означает «не сочетается»."""
        out = self.resolve(ElementRef(a_slug, a_name, a_desc, a_cat),
                           ElementRef(b_slug, b_name, b_desc, b_cat))
        if out.status == "error":
            raise LLMError(out.detail)
        if out.status == "accepted":
            el = out.element
            return {"combinable": True, "name": el["name"],
                    "description": el["description"],
                    "category": el["category"], "glyph": el["glyph"]}
        return {"combinable": False, "status": out.status, "detail": out.detail}

    # ------------------------------------------------------- admin-API (БД)

    def reject_pair(self, a: ElementRef, b: ElementRef, reason: str = "",
                    source: str = "admin") -> StoredDecision:
        d = StoredDecision(pair_key=pair_key(a.id, b.id), a_id=a.id, b_id=b.id,
                           status="rejected", element=None, reason=reason,
                           source=source)
        self.store.put(d)
        return d

    def accept_pair(self, a: ElementRef, b: ElementRef, element: dict,
                    reason: str = "", source: str = "admin") -> StoredDecision:
        d = StoredDecision(pair_key=pair_key(a.id, b.id), a_id=a.id, b_id=b.id,
                           status="accepted", element=element, reason=reason,
                           source=source)
        self.store.put(d)
        return d

    def seed_rejections(self, pairs: Iterable[tuple[ElementRef, ElementRef, str]]) -> int:
        """Массовый перенос запретов в БД: [(a, b, reason), ...]."""
        n = 0
        for a, b, reason in pairs:
            self.reject_pair(a, b, reason)
            n += 1
        return n

    # ------------------------------------------------------------ внутреннее

    def _mock_resolve(self, a: ElementRef, b: ElementRef) -> Outcome:
        proposal, _ = self.mock.propose(a, b)
        if proposal.is_rejection:
            return Outcome("rejected", source="mock", detail=proposal.reason)
        cand = proposal.candidate
        category, glyph, _ = self.classifier.rule_classify(cand.name, cand.description)
        element = {"name": cand.name, "description": cand.description,
                   "category": category, "glyph": glyph}
        return Outcome("accepted", element=element, source="mock")

    def _llm_resolve(self, a, b, key, cached) -> Outcome:
        try:
            hint = None
            if cached and cached.status == "needs_review":
                hint = ("Ранее предложенные варианты были отклонены контролёром "
                        "качества. Предложи другой прямой результат или честно "
                        "откажись.")
            seen: set[str] = set()
            trail: list[dict] = []

            for attempt in range(1, self.cfg.max_candidates + 1):
                proposal, gen_model = self.generator.propose(a, b, hint=hint)

                # (1) генератор отказался — судья проверяет отказ
                if proposal.is_rejection:
                    check, jm = self.judge.confirm_rejection(a, b, proposal.reason)
                    if check.confirmed:
                        reason = check.reason or proposal.reason
                        self.store.put(StoredDecision(
                            pair_key=key, a_id=a.id, b_id=b.id, status="rejected",
                            element=None, reason=reason, source="llm",
                            model=gen_model, judge_model=jm, attempts=attempt))
                        log.info("rejected %s + %s: %s", a.name, b.name, reason[:80])
                        return Outcome("rejected", source="llm", model=gen_model,
                                       judge_model=jm, detail=reason)
                    # судья не согласен: у него есть кандидат — проверим его
                    cand = check.candidate
                    if cand and cand.name.lower() not in seen:
                        verdict, jm2 = self.judge.evaluate(a, b, cand)
                        if verdict.valid:
                            return self._accept(key, a, b, cand, attempt,
                                                gen_model, jm2)
                        trail.append({"name": cand.name,
                                      "rejected_by": "judge",
                                      "reason": verdict.reason})
                    hint = ("Контролёр считает, что прямой результат, возможно, "
                            "существует. Найди его или обоснуй отказ.")
                    continue

                # (2) генератор предложил кандидата — судья оценивает
                cand = proposal.candidate
                if cand.name.lower() in seen:
                    trail.append({"name": cand.name, "rejected_by": "duplicate"})
                    hint = (f"Кандидат «{cand.name}» уже предлагался и отклонён. "
                            "Предложи ДРУГОЙ результат или combinable=false.")
                    continue
                seen.add(cand.name.lower())
                verdict, jm = self.judge.evaluate(a, b, cand)
                if verdict.valid:
                    return self._accept(key, a, b, cand, attempt, gen_model, jm)
                trail.append({"name": cand.name, "rejected_by": "judge",
                              "reason": verdict.reason})
                # фидбек-луп: судья объясняет генератору, что не так
                hint = (f"Кандидат «{cand.name}» отклонён контролёром: "
                        f"{verdict.reason}. Предложи ДРУГОЙ прямой общеизвестный "
                        "результат или верни combinable=false.")

            # (3) попытки исчерпаны — на ручное рассмотрение
            self.store.put(StoredDecision(
                pair_key=key, a_id=a.id, b_id=b.id, status="needs_review",
                element=None, reason="кандидаты отклонены судьёй",
                source="llm", attempts=self.cfg.max_candidates,
                notes=json.dumps(trail, ensure_ascii=False)))
            log.info("needs_review %s + %s: кандидаты %s", a.name, b.name,
                     [t.get("name") for t in trail])
            return Outcome("needs_review", source="llm",
                           detail="все кандидаты отклонены судьёй")

        except LLMError as e:
            # технический сбой: в БД НИЧЕГО не пишем
            log.warning("llm error %s + %s: %s", a.name, b.name, e)
            return Outcome("error", detail=str(e))

    def _accept(self, key, a, b, cand, attempt, gen_model, judge_model) -> Outcome:
        category, glyph, cls_src = self.classifier.classify(cand.name,
                                                            cand.description)
        element = {"name": cand.name, "description": cand.description,
                   "category": category, "glyph": glyph}
        self.store.put(StoredDecision(
            pair_key=key, a_id=a.id, b_id=b.id, status="accepted",
            element=element, reason=cand.reason, source="llm",
            model=gen_model, judge_model=judge_model, attempts=attempt))
        log.info("accepted %s + %s -> %s [%s | judge: %s | cls: %s, попытка %d]",
                 a.name, b.name, cand.name, gen_model, judge_model, cls_src, attempt)
        return Outcome("accepted", element=element, source="llm",
                       model=gen_model, judge_model=judge_model)


def build_service(config: Config | None = None,
                  store: SQLiteStore | None = None) -> AlchemyService:
    return AlchemyService(config or Config.from_env(), store=store)

# Перенесено из прежней DEFAULT_REJECT_PAIRS. Занесите в БД один раз через
# migrate_legacy_rejects() и удалите список. Пары — slug'и "min|max".
LEGACY_REJECT_PAIRS = {
    "ash|bird", "ash|flower", "ash|rainbow",
    "coal|flower", "coal|rainbow",
    "dust|sun",
    "flower|hail", "flower|lightning", "flower|metal", "flower|smoke", "flower|tornado",
    "glass|swamp",
    "hail|bird",
    "rainbow|sandstorm", "rainbow|tornado",
    "sandstorm|fish", "sandstorm|snow",
    "seed|tornado",
}


def migrate_legacy_rejects(service: AlchemyService, id_by_slug: dict) -> int:
    """Один раз перенести старые хардкод-запреты в БД решений.

    id_by_slug — словарь slug -> id элемента (если id элемента и есть slug,
    передайте {s: s for s in ваши_slug'и}).
    """
    moved = 0
    for key in LEGACY_REJECT_PAIRS:
        x, y = key.split("|", 1)
        ax, ay = id_by_slug.get(x), id_by_slug.get(y)
        if not (ax and ay):
            log.warning("миграция: нет элемента для пары %s (пропущена)", key)
            continue
        service.reject_pair(ElementRef(ax, x), ElementRef(ay, y),
                            reason="миграция из хардкода", source="curated")
        moved += 1
    log.info("миграция: перенесено %d запретов", moved)
    return moved

def _selftest() -> int:
    failures: list[str] = []

    def check(cond: bool, msg: str) -> None:
        print(("  ok   " if cond else "  FAIL ") + msg)
        if not cond:
            failures.append(msg)

    # --- утилиты
    check(normalize_name("  стена ") == "Стена", "normalize_name: нормализация")
    check(normalize_name("Water") is None, "normalize_name: латиница запрещена")
    check(normalize_name("Грязь-камень") is None, "normalize_name: дефис запрещён")
    check(normalize_name("A1") is None, "normalize_name: цифры запрещены")
    j = extract_json_object('шум {"a": {"b": 1}} хвост {"c": 2}')
    check(j == {"a": {"b": 1}}, "extract_json_object: первый объект")
    check(extract_json_object("```json\n{\"x\": 1}\n```") == {"x": 1},
          "extract_json_object: ```-обёртка")
    check(pair_key("b", "a") == pair_key("a", "b") == "a|b", "pair_key: симметрия")

    # --- сервис в mock-режиме
    mock = MockBackend(
        reject={"ash|bird"},
        recipes={"brick|brick": Candidate(
            "Стена", "Сооружение из кирпичей", "construction",
            "кирпичи, соединённые вместе, образуют стену")},
    )
    svc = AlchemyService(Config(provider="mock"), store=SQLiteStore(":memory:"),
                         mock_backend=mock)
    brick = ElementRef("brick", "Кирпич", "Обожжённый глиняный блок", "земля")
    ash = ElementRef("ash", "Пепел", "", "земля")
    bird = ElementRef("bird", "Птица", "", "воздух")

    out = svc.resolve(brick, brick)
    check(out.status == "accepted" and out.element["name"] == "Стена",
          "mock: Кирпич+Кирпич=Стена")
    out = svc.resolve(bird, ash)
    check(out.status == "rejected", "mock: Пепел+Птица отклонена (в любом порядке)")

    # --- admin-решения живут в БД
    svc.reject_pair(brick, bird, reason="ручной запрет")
    out = svc.resolve(brick, bird)
    check(out.status == "rejected" and out.source == "db",
          "admin reject: читается из БД")
    svc.accept_pair(brick, ash, {"name": "Кирпичная пыль", "description": "",
                                 "category": "земля", "glyph": "dust"})
    out = svc.resolve(ash, brick)
    check(out.status == "accepted" and out.source == "db"
          and out.element["name"] == "Кирпичная пыль",
          "admin accept: читается из БД (порядок не важен)")

    # --- off-режим: БД работает, отсутствие решения = error, не rejected
    svc_off = AlchemyService(Config(provider="off"), store=svc.store)
    check(svc_off.resolve(brick, ash).status == "accepted",
          "off: accepted-решения из БД работают")
    check(svc_off.resolve(brick, bird).status == "rejected",
          "off: запреты из БД работают")
    stone = ElementRef("stone", "Камень", "", "земля")
    check(svc_off.resolve(brick, stone).status == "error",
          "off: нет решения в БД -> error (НЕ rejected)")

    print()
    if failures:
        print("ПРОВАЛЕНО: %d" % len(failures))
        return 1
    print("Все проверки пройдены.")
    return 0


def _check_env() -> int:
    cfg = Config.from_env()
    print(f"provider       : {cfg.provider}")
    print(f"models         : {', '.join(cfg.models) or '—'}")
    print(f"judge models   : {', '.join(cfg.judge_models) or '—'}")
    print(f"api key        : {'есть' if cfg.api_key else 'нет'}")
    print(f"base url       : {cfg.base_url or '—'}")
    print(f"db path        : {cfg.db_path}")
    print(f"prompt version : {PROMPT_VERSION}")
    print(f"json mode      : {'on' if cfg.json_mode else 'off'}")
    warns = 0
    if cfg.provider == "openrouter" and not cfg.api_key:
        print("!! openrouter без OPENROUTER_API_KEY"); warns += 1
    if cfg.provider == "openai_compatible" and not cfg.base_url:
        print("!! openai_compatible без LLM_BASE_URL"); warns += 1
    if cfg.provider not in ("off", "mock") and not cfg.models:
        print("!! нет моделей (LLM_MODELS)"); warns += 1
    if cfg.provider not in ("off", "mock") and cfg.models \
            and len(cfg.models) < 2:
        print("   (i) одна модель — failover при 429 будет невозможен")
    print("OK" if not warns else f"предупреждений: {warns}")
    return 0


def main() -> None:
    import argparse
    parser = argparse.ArgumentParser(description="Alchemy LLM")
    sub = parser.add_subparsers(dest="cmd")
    sub.add_parser("selftest", help="автотесты без сети (mock)")
    sub.add_parser("check-env", help="диагностика конфигурации")
    p = sub.add_parser("resolve", help="разрешить пару (реальный провайдер из env)")
    p.add_argument("name_a"); p.add_argument("name_b")
    p.add_argument("--cat-a", default="земля"); p.add_argument("--cat-b", default="земля")
    p.add_argument("--desc-a", default=""); p.add_argument("--desc-b", default="")
    args = parser.parse_args()

    logging.basicConfig(
        level=logging.DEBUG if os.environ.get("ALCHEMY_DEBUG") else logging.INFO,
        format="%(levelname)s %(name)s: %(message)s")

    if args.cmd == "selftest":
        raise SystemExit(_selftest())
    if args.cmd == "check-env":
        raise SystemExit(_check_env())
    if args.cmd == "resolve":
        svc = build_service()
        a = ElementRef(args.name_a, args.name_a, args.desc_a, args.cat_a)
        b = ElementRef(args.name_b, args.name_b, args.desc_b, args.cat_b)
        print(json.dumps(asdict(svc.resolve(a, b)), ensure_ascii=False, indent=2))


if __name__ == "__main__":
    main()

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LLM_PROVIDER` | `off` | `openrouter` / `openai_compatible` / `mock` / `off` |
| `OPENROUTER_API_KEY` | — | только для `openrouter` |
| `LLM_API_KEY` | — | только для `openai_compatible` (опционален для Ollama) |
| `LLM_BASE_URL` | — | корень `…/v1` или полный URL `…/chat/completions` |
| `LLM_MODELS` | список free-моделей | первая — основная, остальные — failover |
| `LLM_JUDGE_MODEL` | = основной | отдельная (более сильная) модель судьи |
| `LLM_MAX_CANDIDATES` | `3` | попыток генератора до `needs_review` |
| `LLM_TIMEOUT` | `30` | таймаут HTTP, сек |
| `LLM_JSON_MODE` | `on` | `off`, если провайдер не поддерживает `response_format` |
| `ALCHEMY_DB_PATH` | `alchemy.db` | путь к SQLite с решениями |
| `ALCHEMY_LOG_RAW` | `0` | `1` — логировать сырые ответы моделей |
| `LLM_JUDGE_MIN_SCORE` | `0.6` | порог доп. проверки оценок судьи |

## Порядок внедрения

```bash
python alchemy_llm.py selftest      # без сети, проверяет логику
python alchemy_llm.py check-env     # диагностика конфигурации
python alchemy_llm.py resolve Кирпич Кирпич --cat-a земля --cat-b земля \
    --desc-a "Обожжённый глиняный блок"   # живой прогон с промптами и судьёй
```

Затем в сервере:

1. Один раз выполнить миграцию старых запретов: `migrate_legacy_rejects(svc, id_by_slug)` — и удалить `LEGACY_REJECT_PAIRS`.
2. **Удалить из БД старый мусор** вида `Стена + Стена = Ртуть` — новый промпт старый кэш не исправит.
3. Заменить вызов старого `generate()` на `svc.resolve(...)` и различать статусы (для переходного периода есть `generate_compat`, но `error` в нём честно падает исключением).
4. Хранить `description` у создаваемых элементов (`out.element["description"]`) и передавать обратно в `ElementRef` — это защита от дрейфа смысла.

Два замечания по эксплуатации. Первое: judge удваивает число запросов на новую пару — при лимитах free-моделей учитывайте это в `LLM_MODELS` (ротация-failover компенсирует). Второе: `needs_review` — не мусор, а очередь модерации: трейл попыток лежит в `notes`, админ может позже закрыть пару вручную через `accept_pair`/`reject_pair`, и с этого момента решение будет работать даже при `LLM_PROVIDER=off`.
