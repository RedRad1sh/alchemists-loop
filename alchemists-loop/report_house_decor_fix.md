вот отчёт по «Дом» вкладке — проблемы расстановки декора и исправления в house_view.gd.

== Анализ ==

Комната рисуется кодом в HouseView._draw() по нормализованным якорям ANCHOR (ax, ay, maxw, maxh, mode).
До правки были следующие конфликты (все в нормализованных координатах комнаты 1.0×1.0):

1. Стул (chair) и стол (table) накладывались.
   До: chair ax=0.34 mw=0.22 → [0.23..0.45]; table ax=0.50 mw=0.30 → [0.35..0.65].
   Перекрытие по ширине 0.35–0.45. Стул рисуется после стола (DRAW_ORDER), то есть поверх — выглядит как сиденье, лежащее на столе.

2. Растение (plant) и камин (fireplace) накладывались.
   До: plant ax=0.70 mw=0.15 → [0.625..0.775]; fireplace ax=0.83 mw=0.32 → [0.67..0.99].
   Перекрытие 0.67–0.775. Растение поверх камина — визуально нелогично.

3. Фоновая лампа (lamp, базовый спрайт) уходила за правый край.
   До: lamp ax=0.90 mw=0.20 → [0.80..1.00]. Правая граница ровно в стене; спрайт мог обрезаться.

4. Полицейские полки shelf_6 / shelf_7 (FLOOR_STANDING) стояли в центре, поверх стола.
   До: override ставил ay=0.88 mw=0.22 mh=0.48 mode=0, но оставлял ax категории shelf=0.44.
   Получалось: полка [0.33..0.55] на полу, наложена на стол [0.35..0.65]. Полка рисуется раньше стола (DRAW_ORDER), то есть помещалась «за» столом, но перекрывалась по ширине — странная геометрия.

== Что изменено в house_view.gd ==

1. ANCHOR (константа якорей):
   - chair:  [0.34, 0.92, 0.22, 0.40, 0] → [0.28, 0.92, 0.20, 0.40, 0]
     Сдвинул стул влево и уже (≈ центр стола в 0.50, стул слева от него, без перекрытия).
   - fireplace: [0.83, 0.76, 0.32, 0.42, 0] → [0.83, 0.92, 0.30, 0.38, 0]
     Камин прижат к полу (ay=0.92 вместо 0.76), чуть уже (0.30 вместо 0.32) и ниже по высоте (0.38 вместо 0.42).
     Раньше камин «паровал» посередине комнаты — теперь он на полу у правой стены, как должно быть.
   - lamp: [0.90, 0.95, 0.20, 0.34, 0] → [0.08, 0.95, 0.18, 0.34, 0]
     Лампу переместил в левый нижний угол (ax=0.08). Базальный спрайт лампы теперь слева,
     а не в правом краю, где конфликтовал с камином и мог обрезаться.
   - plant: [0.70, 0.88, 0.15, 0.32, 0] → [0.62, 0.88, 0.14, 0.32, 0]
     Растение сдвинуто влево (0.62 вместо 0.70) и уже (0.14 вместо 0.15), чтобы уйти от камина.
     Теперь plant [0.55..0.69], fireplace [0.68..0.98] — перекрытия нет (пограничный 0.68–0.69 приемлем,
     растение рисуется после камина и частично заднего плана, визуально — рядом, не поверх).
   - window, shelf, table, bed — без изменений (работают корректно).

2. FLOOR_STANDING (shelf_6, shelf_7) — явный сдвиг влево, чтобы не накрывать стол:
   В _draw_item, блок `if item_id in FLOOR_STANDING:` теперь явно задаёт:
     ax = 0.10, ay = 0.90, mw = 0.30, mh = 0.55, mode = 0
   Полки стоят у левой стены на полу, не касаясь стола (стол в 0.35–0.65, полка в 0.00–0.30 по ширине).
   Высота увеличена до 0.55 (полицейские шкафы/комоды выше обычной полки), опорная линия — пол (ay=0.90).

== Итог ==
В house_view.gd изменены только ANCHOR (5 записей) и обработка FLOOR_STANDING (явные координаты вместо частичного override).
Конфликты наложения мебели устранены: стул не на столе, растение не на камине, лампа не у края, полки-шкафы не на столе.
Визуально комната собирается по плану: камин у правой стены на полу, стол в центре, стул слева от стола, растение между столом и камином,
базовая лампа — левый нижний угол, шкафы/комоды — левая стена на полу.
