# Online.gd UX-патч (docs/refactor online.gd.md §1–16) — план реализации

> **For Claude:** Используй скилл executing-plans (батчи с чекпойнтами) и TDD
> на selftest-раннере проекта (`tests/selftest.gd`, `Selftest.check`,
> сюита `tests/suite_resonance_net.gd`). GUT/gdUnit4 в проекте нет.

**Goal:** Встроить в `game/online.gd` UX-слой из дока: тосты, индикатор сети,
телеграф QTE, CanvasLayer для QTE, безопасное позиционирование, умный выбор
события, цветной таймер, адаптивные награды, вибрация — без переписывания класса.

**Architecture:** Всё живёт в `Online` (RefCounted, держит `g: Game`). Глобальный
UX-слой — `CanvasLayer(layer=20)`, QTE — свой `CanvasLayer(layer=15)`. Тесты —
новая сюита `tests/suite_online_ux.gd` + врезка в `Selftest.run`.

**Tech stack:** Godot 4.7 GDScript, selftest-раннер проекта.
