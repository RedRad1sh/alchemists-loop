# Цикл «Зачем возвращаться» — анализ + промпт для генерации идей

> Исторический документ. В текущей реализации Производство ослаблен до 10 с/3 операций/3 шт.; Линза и «Что варить?» не являются пользовательскими UI; подсказка Светика возвращена одним платным каналом, Родник находится в Лаборатории, а Отголоски — в Мире. См. `docs/ui-refactor-e2e-2026-09-16.md`.


Статус: дизайн-документ (v24, до реализации). Согласуем направление → потом кодим.

---

## 1. Суть вопроса

Игра уже даёт **бесконечный контент** (LLM-сервер генерирует новые вещества) и **короткую idle-петлю** (эфир, Родник, Верстак, Дары). Но «бесконечный контент» ≠ «повод вернуться». Вопрос стоит иначе:

> Какое **обещание** мы даём игроку в момент закрытия игры, которое созреет к его возвращению?

В кликерах/alchemy-играх возврат держится не на «ещё один рецепт», а на **таймере, который зреет без игрока**, и на **событии, которое произошло без него и касается лично его**.

---

## 2. Как это устроено у других (и что берём)

| Игра | Механика возврата | Забираем к себе? |
|---|---|---|
| **Little Alchemy 2** | Конечный контент (≈720), «осталось 3 из 720» — Зейгарник-эффект | Частично: счётчики «N из M» у нас есть, но контент бесконечен — не работает как финиш |
| **Infinite Craft** | «А что если?» — виральная любознательность, бесконечные комбо | **Да, это наш козырь**, но нужен «крючок» для возврата, а не только первая сессия |
| **Cookie Clicker / Adventure Capitalist** | Таймеры-улучшения зреют без тебя; офлайн-доход; «золотая печенька»/событие | Частично есть (офлайн-эфир 8ч). Слабо: награда «серая» |
| **Neko Atsume / Animal Crossing** | «Кто приходил, пока меня не было» — возвратная сводка | **Да — главный паттерн для нас** (см. §6, «Сводка возврата») |
| **Merge Mansion / Gardenscapes** | Энергия + ежедневные задания + сезонные «гвозди» | Частично: ежедневная цель и заказы есть, но не связаны в один «дневной круг» |
| **Stardew / мобильные фермы** | Мягкий streak, сезонные ивенты, «к утру созреет» | Частично: сезонов нет; streak нет |
| **Hades / roguelite-мета** | После смерти — перманентный прогресс, «ещё один забег» | Аналог у нас — «Перегонка» (престиж), уже есть |

Вывод: **не хватает двух вещей** — (а) возвратной сводки «что случилось без тебя» и (б) одного видимого «дневного круга» с наградой за полное закрытие.

## 3. Что уже есть (активы, которые грех не использовать)

**Короткий цикл (секунды–минуты):**
- Эфир: реген ~2/с, кап 200 (базовый), варка 10⚡.
- Родник: +1 выбранный базовый элемент каждые 6 с.
- Верстак: автоварка цели каждые 8 с, лимит 5.
- Дары: +1 случайное открытое каждые 120 с (апгрейд).
- Офлайн-накопление эфира до 8 ч.

**Суточный цикл (есть, но слабый):**
- Цель дня: целевой ингредиент, личные очки → только в рейтинг.
- Заказы гильдии: 3/день, награда ⚡, +100⚡ за все три.
- Очкам цели дня ничего «не покупается» → мотивация вялая.

**Мета:**
- Достижения, задания Светика, комплекты (сеты по категориям) — дают **постоянные** бонусы к капу/регену (это требование проекта, сохраняем).
- Перегонка (престиж): от 30 веществ → Золото мудрецов.
- Светик: компаньон с аффинити/уровнями, диалогами, заданиями.

**Социальное/уникальное (наше главное преимущество):**
- **LLM-сервер = бесконечный, порождаемый сообществом контент**: каждый игрок может первым открыть вещество, которого нет ни у кого в мире.
- Живая лента мира, зал славы, рейтинг (открытия/вещества/очки), дома других игроков.
- Дом Светика — витрина (темы, ауры, мебель, произвольные цвета).

**Жёсткие ограничения проекта (не ломать):**
- Компаньон — только «Светик».
- Бонусы заданий/достижений — постоянные (кап/реген), не только разовый эфир.
- Каждый промпт LLM: `max_completion_tokens: 512`, `reasoning_effort: "none"`.
- БД сервера — источник истины; дубли имён недопустимы; серверные открытия переживают рестарт клиента.
- Намёки не предлагают пары из `rejected_pairs`; у Линзы свой перк.
- Светик компактный, справа сверху, не перекрывает контент.

## 4. Ключевая проблема текущего дизайна (честно)

1. **Межсессионный «крючок» отсутствует.** Всё, что зреет без игрока, зреет минуты (родник/верстак/эфир). Единственные суточные вещи — цель дня и заказы — **пассивны и незрелищны**: игрок не чувствует, что «в его отсутствие что-то произошло».

2. **Очки цели дня ничего не дают.** Замкнутый контур «очки → рейтинг» слаб для казуального игрока. Нужен видимый результат в первые 30 секунд.

3. **Первооткрытие не оставляет «следа».** Игрок открыл уникальное вещество → оно ушло в мир. Нет обратной связи: «твоё вещество породило 3 новых, пока тебя не было». А ведь именно это — аналог Neko Atsume и главный социально-нарративный крючок, который **не может** скопировать ни одна другая алхимия с конечным контентом.

4. **Нет горизонта недели/сезона.** Контент бесконечен, но цели конечны и одноразовы. Нужен цикл, который «обнуляется» и даёт новый старт (сезон), чтобы «ещё один забег» был и на длинной дистанции.

## 5. Кандидаты петель (с оценкой)

### A. «Живой мир»: потомки моих веществ + сводка возврата ⭐ уникальный козырь
- **Механика:** сервер помнит, кто первооткрыл вещество. Когда вещество X (моё) участвует в чужой успешной паре, сервер пишет «потомка» с родителем X. При моём возврате — сводка: «Мир открыл N веществ; из ТВОИХ открытий родилось M; твой рейтинг #X (был #Y)».
- **Почему:** единственная механика, которую не может повторить ни один конкурент (нужен живой LLM-мир + сообщество). Возврат = любопытство («что из моего выросло?») + гордость (твоё вещество в чужих играх).
- **Риск:** нужна серверная таблица lineage; на малой аудитории событий мало (лечится: ИИ-«соседи»/симулированный мир как fallback — но это обсуждаемо).
- **Трудоёмкость:** средняя (сервер: таблица + эндпоинт; клиент: сводка).

### B. «Дневной круг»: streak + ежедневная награда + недельный бонус
- **Механика:** один экран «Дневной круг»: цель дня, 3 заказа, N открытий за день. За закрытие всех — награда дня; серия дней подряд (мягкий streak, **без штрафа за пропуск**) — растущий постоянный бонус к капу/регену; 7-й день — «легендарная пара» (уникальный рецепт-подсказка или декор).
- **Почему:** превращает существующие разрозненные суточные механики в один видимый контур с прогрессом и наградой. Отвечает «зачем открыть завтра».
- **Риск:** мягкий streak обязателен — жёсткая потеря серии отталкивает одиночек.
- **Трудоёмкость:** низкая-средняя (клиент в основном; сервер — только если streak хранить).

### C. «Музей / зал славы»: коллекция + первоткрытия как статус
- **Механика:** отдельная витрина «моих первоткрытий» с редкостью (слой/тир), титулы первооткрывателя, счётчик «твоё вещество в чужих домах/ленте». Коллекционные сеты получают «не хватает 1»-подсветку.
- **Почему:** усиливает A и даёт гордость/статус. Зейгарник («остался 1 элемент комплекта») даёт конкретный повод допахать.
- **Риск:** низкий; это скорее «обвязка» A и B.
- **Трудоёмкость:** низкая.

### D. Сезонная доска (soft reset)
- **Механика:** раз в N недель — новая «доска алхимии» с обнуляемым прогрессом и сезонным эксклюзивом (декор дома, аура, титул). Летопись прошлых сезонов остаётся.
- **Почему:** даёт горизонт «ещё один забег» без потери вечного прогресса (как Hades).
- **Риск:** дороже всего; имеет смысл после A/B.
- **Трудоёмкость:** высокая.

### E. «Сосед»/социальное соперничество (витрина + посещения)
- **Механика:** «твой дом посетили K раз», «гость оставил след», реакция на чужой дом.
- **Почему:** дешёвый соц-крючок поверх уже готовых домов и рейтинга.
- **Риск:** низкий. Частично усиливает A/C.

### F. Таймер-обещание («вернись к вечеру»)
- **Механика:** редкое «событие мира» с таймером созревания (часы), анонсируемое заранее: «Через 6 часов в мире случится…».
- **Почему:** классический «возврат к конкретному времени» (как смолы в gacha).
- **Риск:** конфликтует с «мистическим» характером событий; время игрока ≠ время сервера. Средний приоритет.

## 6. Рекомендация (композиция, а не одна фича)

**«Три якоря возврата»** — по горизонту времени:

1. **Якорь-минуты** (уже есть, не трогаем): эфир/Родник/Верстак/Дары.
2. **Якорь-сутки** — **«Дневной круг»** (B): сводим цель дня + заказы + «открой N за день» в один экран с прогрессом, ежедневной наградой и мягким streak'ом, дающим **постоянный** бонус к капу/регену.
3. **Якорь-неделя/сезон** — **«Живой мир»** (A + C + E): возвратная сводка «что случилось без тебя», потомки твоих веществ, музей первоткрытий, витрина дома. Поверх — сезонная доска (D) как следующий крупный шаг.

**Одна ключевая фича первого приоритета — «Сводка возврата»**: при запуске после паузы (от ~30 минут) показывать компактный экран:
> «Пока тебя не было: мир открыл **12** веществ, из твоих открытий родилось **3** новых, твой рейтинг **#14** (был #19), Родник накопил **18** «Воды», Светик скучал.»

Это паттерн Neko Atsume / Animal Crossing, который у нас работает **уникально** за счёт живого LLM-мира. Именно он отвечает на вопрос заголовка: «зачем открывать снова?» — «потому что мир изменился без тебя, и часть этих изменений — твоя заслуга».

**Метрика проверки любой будущей механики:** отвечает ли она «зачем открыть завтра/на неделе» и даёт ли видимый результат в первые 30 секунд сессии?

```
Ты — геймдизайнер мобильных idle/алхимических игр (жанр Little Alchemy 2,
Infinite Craft, Cookie Clicker, Neko Atsume, Merge Mansion). Дай 8–12 конкретных,
готовых к реализации механик удержания для нашего проекта. НЕ пересказывай общие
советы — выдай механику → формулу → таймеры → награды → где лежит на клиенте/сервере.

== КОНТЕКСТ ПРОЕКТА (факты, не меняй их) ==
- Игра «Петля Алхимика» (кликер-алхимия) на Godot 4 + Python/FastAPI-сервер.
- Ядро: соединяем 2 вещества → новое. Варка стоит 10⚡ и занимает секунды.
- Эфир (⚡) — энергия: реген ~2/с, базовый кап 200, растёт апгрейдами.
- Сервер генерирует НОВЫЕ вещества через LLM (OpenRouter): контент бесконечный,
  а главное — создаётся сообществом. Каждый игрок может первым открыть вещество,
  которого нет ни у кого. Решение пары фиксируется в БД навсегда (БД = истина).
- Живая лента мира (кто что открыл), зал славы, рейтинг (открытия/вещества/очки),
  дома других игроков, аватары.
- Суточное: цель дня (личные очки) и 3 заказа гильдии (детерминированы от даты).
  Очки цели дня пока ни на что не влияют, кроме рейтинга.
- Idle-автоматизация: Родник (+1 базовый элемент/6с), Верстак (автоварка цели/8с,
  лимит 5), Дары (+1 случайное/120с), офлайн-эфир до 8ч.
- Мета: достижения/задания/комплекты дают ПОСТОЯННЫЕ бонусы к капу и регену
  (не только разовый эфир) — это требование, сохраняй. Престиж «Перегонка»
  (от 30 веществ) даёт «Золото мудрецов».
- Компаньон «Светик» — единственный; даёт намёки (не предлагает пары из
  rejected_pairs), задания, диалоги, аффинити/уровни; живёт компактно справа сверху.
- Дом Светика — витрина: темы, ауры, мебель (9 категорий × 10), произвольные цвета.

== ПРОБЛЕМА (решай именно её) ==
У игрока нет повода вернуться ЗАВТРА/на неделе. Всё, что «зреет без игрока»,
зреет минуты. Нужен ответ на вопрос «зачем открыть снова», опирающийся на наш
козырь — живой LLM-мир и сообщество. Требуется возвратный крючок, который
невозможно скопировать в игре с конечным контентом.

== ЖЁСТКИЕ ОГРАНИЧЕНИЯ ==
1. Не предлагай вторую валюту, обесценивающую ⚡ и Золото мудрецов.
2. Постоянные бонусы (кап/реген) важнее разового эфира.
3. Streak — только «мягкий» (награда за серию, БЕЗ штрафа за пропуск).
4. Каждый запрос к LLM содержит max_completion_tokens:512 и reasoning_effort:"none";
   не нагружай LLM сверх этого (никаких больших генераций за один запрос).
5. Клиент — одиночная сцена на Godot; UI уже плотный (вкладки-хаб «Инструменты»).
   Механика должна влезать в существующую структуру вкладок/попапов.
6. Сервер — SQLite (FastAPI); новые таблицы/эндпоинты допустимы, но дёшево.
7. Игрок одиночный, аудитория малая → механики не должны умирать без толпы
   (дай fallback на «тихое» существование при 5–50 игроках).
8. Всё на русском; тон — уютный, «лаборатория и маленький светлячок Светик».

== ЧТО ВЫДАТЬ ==
По каждой механике (8–12 шт.), строго по шаблону:
1. Название + одна строка сути.
2. На какой вопрос игрока отвечает (почему откроет игру).
3. Конкретика: таймеры, числа, формулы наград, что обнуляется/что вечно.
4. Что потребует на клиенте и на сервере (таблицы/эндпоинты/экран).
5. Риск и как смягчить (особенно: малая аудитория).
6. Горизонт возврата: минуты / сутки / неделя / сезон.

Отдельно в конце: ТОП-3 механики по соотношению «ретеншн / трудоёмкость»
с обоснованием, и предложи, что реализовать первым.
```

## 8. Следующие шаги

1. Ты прогоняешь промпт через другие модели (или решаем сразу по этому документу).
2. Сводим идеи в короткий список, выбираем приоритет (рекомендация: начать с «Сводки возврата» + «Дневного круга»).
3. Реализуем по пунктам с тестами (клиент selftest + сервер pytest), как в прошлых раундах.

Скажи, когда готов выбрать направление — распишу технический план под конкретные механики.
