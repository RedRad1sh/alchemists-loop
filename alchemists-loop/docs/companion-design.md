# Дух-компаньон «Светик» — мини-дизайн-док

> Статус: исторический дизайн-док; применённый UI-рефакторинг описан в `docs/ui-refactor-e2e-2026-09-16.md`.
> Формат игры 540×960, Godot (клиент) + FastAPI/SQLite/LLM (сервер).
> Графика — процедурная кодом, без внешних ассетов. Язык — русский.
>
> В текущем UI есть одна платная подсказка Светика за эфир; она показывает направление без раскрытия результата. Старый free-reveal путь оставлен
> только как отключённый compatibility stub. Светик сохраняет оформление, диалог,
> реакции и дружбу, но не выдаёт бесплатный результат рецепта.

---

## 1. Цель

Игра умирает в первый день, потому что у неё нет **эмоционального якоря**: варка —
бесконечная механика, мир — пассивный список, игрок один. Компаньон закрывает это:

- даёт **персонажа, к которому возвращаются** («зайду проверить Светика»);
- превращает кнопку «Намёк» из скучной утилиты в **живое общение**;
- делает мир **говорящим**: дух сплетничает о чужих первооткрытиях;
- помнит игрока — это единственная игра, которая **знает тебя**.

Отличие от «питомцев» других игр: дух живёт в **общем AI-каноне** — он знает и твои
открытия, и открытия всего мира, и может комментировать их по-настоящему.

---

## 2. Кто это

- **Имя по умолчанию «Светик»** (отсылка к веществу `spark` из стартового графа).
  Игрок переименовывает духа при знакомстве → персонализация = привязанность.
- **Визуал (процедурный, `_draw()`):** капля света / язычок пламени с двумя глазами;
  цвет и аура меняются от настроения и уровня отношений; моргает, «дрожит» при
  тумане, вспыхивает при первооткрытии. Партиклы — `CPUParticles2D` (искры).
- **Характер:** тёплый, любопытный, слегка ехидный, без пафоса. Говорит коротко.

Примеры реплик:

| Момент | Реплика |
|---|---|
| Знакомство | «О! Наконец-то. Я — искра, что не гаснет в твоём котле. А тебя как звать, алхимик?» |
| Успех (Пар) | «Ого, „Пар“! Тёплый и мятежный — прямо как мой характер.» |
| Туман | «Туман, бывает. Даже у лучших. Подмешай воду — она всё смягчает.» |
| Первооткрытие | «Тише… слышишь? Это мир тебя запомнил. „Ртуть“ — твоё, первое во всех петлях.» |
| Возврат | «Ты вернулся! Пока тебя не было, мир нашёл „Ртуть“. Успеем своё?» |
| Простой | «Котёл скучает. А скучающий котёл — грустный котёл.» |

## 3. Механики

### 3.1 Триггеры → реплики

Таблица «событие → реакция». **80% реплик — локальный банк** (мгновенно, офлайн),
LLM — только для «сочных» моментов (лор-факт, подсказка, сплетня).

| # | Триггер | Источник | Реакция |
|---|---|---|---|
| 1 | Знакомство (первый запуск) | локально | представление + выбор имени |
| 2 | Успешная варка нового элемента | локально + LLM-лор (по желанию) | радость + 1 строка лора |
| 3 | Варка известного рецепта | локально | «мы это знаем» + намёк на автоварку |
| 4 | Туман (несочетаемое) | локально | утешение + мягкая подсказка |
| 5 | Первооткрытие (`status="created"`) | локально | фанфары, «ты первый в мире» |
| 6 | Возврат в игру (>4 ч) | локально + LLM-сплетня | приветствие + сводка мира |
| 7 | Чужое открытие (тикер) | локально | сплетня |
| 8 | Юбилей (10/50/100 варок) | локально | поздравление + награда |
| 9 | Простой (нет действий ~60 с) | локально | «котёл скучает» |
| 10 | Открытие Человека (режим-гейт) | локально | лор-реплика |

### 3.2 Подсказки (историческая, superseded)

> Этот раздел описывает старую ветку дизайна и не является текущим контрактом.
> В актуальном UI нет кнопки «Намёк», Светик не раскрывает результат рецепта,
> а неизвестная пара проверяется через Experiment/server discovery.

Кнопка «Намёк» (`_hint()` в `main.gd`) исторически переезжала в **диалог с духом**. Уровни:

1. **Шёпот** — категория/направление: «ищи в воде, что-то холодное». Бесплатно, кулдаун.
2. **Намёк** — один из двух ингредиентов назван: «второй — огонь». Цена ~текущий `HINT_COST`.
3. **Почти ответ** — готовая пара из `_hint_candidates()`. Дороже, или раз в день бесплатно.

Уровни 2–3 генерит **сервер** (у него весь граф + мировые открытия), падая на
локальный `_hint_candidates()` при недоступности. Дух озвучивает подсказку «своим
голосом» — это не системное сообщение, а реплика.

### 3.3 Отношение (affinity)

Растёт от: варок, первооткрытий, ежедневного визита. Уровни:

| Уровень | Название | Бонус |
|---|---|---|
| 1 | Знакомец | базовая болтовня |
| 2 | Приятель | 2 бесплатных шёпота в день |
| 3 | Друг | новая аура духа, скидка на намёки |
| 4 | Наперсник | уникальные реплики, бонус эфира за юбилеи |

### 3.4 Память

Серверная таблица `companion_state` (ключ — `device_id`): имя игрока, имя духа,
affinity, счётчики (варки, первооткрытия), последний визит, флаги ключевых событий,
любимая стихия. Офлайн-фоллбэк — минимальный локальный набор.

### 3.5 Сплетни о мире

Мостик к фиче №2 (гонка). Дух изредка говорит: «Слышал, вчера кто-то открыл „Ртуть“».
Источник — последние события из `/api/world`/нового `/api/events`. В MVP — одна
реплика при возврате; позже — живой тикер.

## 4. UI

- Дух сидит **в углу лаборатории** (вкладка 0) и на вкладке «Мир»; тап по нему —
  открыть панель диалога.
- **Пузырь реплик** над духом (автоскрытие через ~6 с), тап — развернуть в **панель**:
  история (последние ~10), кнопки-ответы (для выбора имени / запроса подсказки).
- Анимации: появление, моргание, вспышка при первооткрытии, «дрожь» при тумане.
- Без свободного ввода в MVP (кнопки-ответы); свободный чат — фаза 3.

---

## 5. Сервер

- **`POST /api/companion/talk`** — `{device_id, trigger, context}` → `{ok, reply, mood, hint?}`.
- **`GET /api/companion/state`** / авто-обновление через `talk` — чтение/запись состояния.
- **Таблица `companion_state`** (`device_id` PK, `player_name`, `spirit_name`,
  `affinity`, `streak`, `last_seen`, `counters`, `flags`).
- **LLM-вызовы точечные и лимитированные** (не чаще 1 на ~20 с на игрока, очередь),
  провайдеры/ротация — переиспользуем `gen_llm.py`. Промпт-система: «Ты — Светик…»,
  данные о мире встраиваем в текст запроса (файлы модели недоступны).
- **Безопасность/стоимость:** модель возвращает только реплику (≤160 символов,
  кириллица); экономику/правила не видит; любая ошибка → локальный банк реплик.

---

## 6. Клиент (Godot)

- Новый узел `game/companion.gd` (спрайт `_draw()`, mood-цвета, партиклы) +
  `game/companion_bubble.gd` (пузырь) + панель диалога.
- Хуки в существующий код:
  - `_on_brew_success` / `_set_status` — триггеры 2–4;
  - `_on_net_discover_result` (`status == "created"`) — триггер 5;
  - `_ready`/таймер простоя — триггеры 6, 9;
  - `_hint()` — перенаправление на диалог подсказок (3.2);
  - `_build_world` / `_event_btn` («☄ Событие…») — сплетни и события.
- Локальный банк реплик в `companion.gd` (по триггерам и стихиям) — офлайн-фоллбэк.

---

## 7. Экономика

- Шёпот — бесплатно (кулдаун/лимит в день по affinity).
- Намёк / почти-ответ — эфир (уровень 3 = дешевле при высоком affinity).
- Награды: за юбилеи и рост affinity — эфир/косметика. Игра не блокируется.

---

## 8. Офлайн и деградация

Без сервера дух **полностью рабочий**: болтовня, утешение, простые подсказки —
из локального банка; нет только лор-фактов LLM и сплетен. Никаких зависаний UI.

---

## 9. Фазы

- **Фаза 1 (ядро, ~1 день):** спрайт + пузырь + панель; триггеры 1–5, 9; знакомство
  с выбором имени; подсказки уровня 1–2 (сервер, фоллбэк локально); офлайн-банк.
- **Фаза 2:** affinity + память на сервере + награды; сплетни о мире; косметика духа.
- **Фаза 3:** свободный диалог; связка с гонкой первооткрытий (фича №2) — дух
  объявляет ежедневную цель.

---

## 10. Критерии приёмки (фаза 1)

- [ ] Дух появляется в лаборатории, моргает, реагирует на варку/туман/первооткрытие.
- [ ] Знакомство: спрашивает имя игрока, предлагает назвать себя; имя сохраняется.
- [ ] «Намёк» вызывается через диалог с духом и даёт подсказку (уровень 1/2).
- [ ] Офлайн: без сервера все триггеры дают локальные реплики, ничего не падает.
- [ ] Selftest клиента зелёный; серверные тесты зелёные (`companion_state` CRUD + talk).
- [ ] Реплики ≤160 символов, на русском, без разметки.

## 11. Риски

- **Задержка LLM** — решено: LLM только для лор/подсказок, болтовня локальная.
- **Стоимость вызовов** — решено: rate-limit + кэш лор-фактов в БД (колонка `lore`).
- **«Кринж»-диалоги** — решено: короткие реплики, тон зафиксирован примерами в промпте.
