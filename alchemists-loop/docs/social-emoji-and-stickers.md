# Эмодзи и стикеры социальной системы

> Для чата, ленты открытий, гостевой книги домика, реакций на первооткрытия,
> системных тостов и пуш-уведомлений. Дизайн-якорь: **ночная лаборатория +
> тёплая капля-светлячок Светик**; палитра — бирюза `#3FAFBF`, янтарь `#E6BD6B`,
> тёмно-синий материи, светлый текст `#F0F7FF`.
>
> Два слоя:
> 1. **Эмодзи** — Unicode-символы, работают везде (пуши, чат, лента, тосты).
> 2. **Стикеры** — полноразмерные иллюстрации в стиле спрайтов Светика
>    (`game/spirits/*.png`), реакции на события и большие поздравления.

---

### Редкости как цветные круги (альтернатива, более читаемая на тёмном фоне)
Если хотите строже привязаться к цветам палитры игры:

| Редкость | Эмодзи | Цвет тинта (через `add_theme_color_override` или BBCode `[color=...]`) |
|---|---|---|
| Обычное | ⚪ | `#A6B3BF` |
| Необычное | ✦ | `#3FAFBF` (бирюза) |
| Редкое | ✧ | `#A57BE3` (аметист, ввести в палитру как третий акцент) |
| Эпическое | ❂ | `#E6BD6B` (золото) |
| Легендарное | ✺ | радужный tween (`#E6BD6B → #FF8FA3 → #3FAFBF`) |

> Если движок не умеет красить Unicode-экранизации, используйте отдельный
> `Label` с эмодзи + наложенный `ColorRect`-маркер слева (как у орбов
> редкости уже работает).

## 2. Системные тосты и пуши — готовые пары «эмодзи + текст»

Сообщения соц. слоя и сетевого UX (`game/online.gd` → `_toast`). Используют
один эмодзи в начале строки, без двойных.

| Событие | Эмодзи | Текст (русский, ≤ 40 символов) |
|---|---|---|
| Успешная варка (известное) | 🫧 | «Пар готов» |
| Новое открытое (локально) | ✨ | «Открыто: **%s**» |
| Первооткрытие в мире | 🌠 | «Ты первый в мире: **%s»** |
| Повторное первооткрытие | 🌍 | «**%s** открыт(а) алхимиком `%s`» |
| Туман (не сочетается) | 🌫️ | «Туман рассеялся… вещества не сошлись» |
| Нет сети / мир недоступен | 📡 | «Мир спит — варю локально» |
| Сеть вернулась | 🟢 | «Мир на связи» |
| Идёт серверная проверка | … | «Мир думает…» |
| Подсказка Светика | 💡 | «Светик шепчет: …» |
| Нет эфира | ⚡ | «Мало эфира» |
| Лунки очищены | ✕ | «Лунки сброшены» |
| Пара поставлена | 🔂 | «Пара повторится» |
| Награда эфиром | ⚡ | «+%d ⚡» |
| Награда дружбой | 💛 | «+%d дружбы» |
| Оверфлоу | ✨ | «+%d ⚡ в запас» |
| Уровень дружбы | 💛 | «Светик стал ближе» |
| Достижение | 🏅 | «Достижение: **%s»** |
| Задание | 📜 | «Задание: %s» |
| Заказ выполнен | 📋 | «Заказ закрыт: +%d ⚡» |
| Достигнута цель дня | ☀️ | «Цель дня: выполнено!» |
| Первое в дне — фанфары | 👑 | «Первый в дне: **%s**!» |
| Гость в домике | 🚪 | «К тебе заглянул гость» |
| Визит засчитан | 👣 | «След оставлен» |
| Эссенция оставлена | 💠 | «Эссенция оставлена» |
| Находка Жилы | 💧 | «Жила откликнулась» |
| Влито в Жилу | ✨ | «Капля влита в Жилу» |
| Стрик Жилы | 🔥 | «Серия Жилы: %d» |
| Круг: ранг | 🕯️ | «Огонёк очага: ранг %s» |
| Круг: очки | 🕯️ | «+%d очка Круга» |
| Отголосок | 🔮 | «Отголосок мира…» |
| Реторта готова | ⚗️ | «Реторта созрела» |
| Офлайн-возврат | 💤 | «Пока тебя не было…» |
| Ошибка сети | ❌ | «Заповедь мира не дошла» |
| Покупка | 🎁 | «Получено: %s» |
| Новый день/цель | ☀️ | «Новая цель: %s» |
| Неделя: ярмарка | 🗓️ | «Ярмарка открыта» |
| Престиж | 🜛 | «Перегонка начата» |

В пуше-уведомлении Android эмодзи ставится **в начале** title, body — чистый
текст без разметки (пуши ANS-ограничены по длине, один эмодзи даёт +10–15%
CTR и лучше читается в шторке).

## 3. Реакции к сообщениям / чужим открытиям (быстрый реагиролл)

Лайки и реакции — один эмодзи, 6–8 вариантов. Должны быть **понятны без
объяснения** и не пересекаться с системными эмодзи по смыслу. Набор для
социальной ленты и гостевой книги домика:

| Код | Эмодзи | Название | Когда уместно |
|---|---|---|---|
| `r_spark` | ✨ | Искра | Восторг от открытия |
| `r_fire` | 🔥 | Огонь | Крутое/эпичное |
| `r_wow` | 😮 | Ух-ты | Первооткрытие / редкое |
| `r_tea` | 🫖 | Чаёк | Уютно, завариваю |
| `r_hearth` | 🕯️ | Очаг | Оценка домика/уюта |
| `r_svetik` | 💛 | Светик | Тепло/спасибо |
| `r_think` | 🤔 | Думаю | «а что, если?» |
| `r_mist` | 🌫️ | Туман | «у меня тоже не сошлось» |

> Для Android-экономии трафика храните реакции как short-code строки
> (`"r_spark"`), в клиенте мапите в эмодзи через таблицу. При расширении
> набора старые short-code'ы не переименовывать.

## 4. Стикеры Светика (8 стикер-паков для соц. слоя)

Каждый стикер — PNG 512×512 (и @2x 1024 для превью) в стиле существующих
спрайтов `game/spirits/*.png` (та же рисовка капли, тот же контур, те же
глаза). Стикер — это крупный Светик + минимум аксессуаров + одно
эмоциональное состояние. Используются как:

- реакция на чужое первооткрытие в ленте;
- поздравление в гостевой книге;
- фанфарное сообщение Светика в ответ на собственное достижение;
- превью/бейдж награды;
- пуш-картинка.

Имена файлов предлагаются под тот же нейминг, что и существующие спрайты:
`assets/spirits/stickers/<id>.png`.

### Технические требования к стикерам

1. **Размер:** 512×512 основной, 1024×1024 master (для андроид-пушей и
   превью в чате); фон **прозрачный**. Отступ ~32 px со всех сторон, чтобы
   не прилипало к краям баббла.
2. **Стиль:** пиксель-арт ручной отрисовки **идентично** `idle.png` —
   каплевидный контур с коричневой обводкой ~3 px, внутренняя растушёвка
   «тёплый центр → насыщенный край» (градиент от светло-жёлтого пупка к
   оранжевому/янтарному контуру), глаза с белком и чёрной точкой-зрачком,
   такие же два блика в зрачке.
3. **Цвета:**
   - базовый цвет Светика — `#E88C3A → #FFEFD1` (как `idle.png`);
   - акцент в стикерах — бирюза `#3FAFBF` и янтарь `#E6BD6B` (те же, что
     в `ui_style.gd` и `btn_primary.png`/`btn_gold.png`);
   - серый для грусти — `#6F7278 → #C9BAA0` (как `sad.png`);
   - никаких ярко-кислотных и розово-фиолетовых — выбиваются из уютной
     лабораторной палитры.
4. **Анатомия:** у Светика **нет рта** — эмоция передаётся формой глаз
   (как у CalArts-капли: круглые = удивление, ^_^ дуги = смех, чёрные
   треугольники злости = грусть по `sad.png`) и положением тела/искр
   вокруг. Не добавлять рот, это ломает канон существующих спрайтов.
5. **Имя/текст на стикере — нет.** Весь текст идёт отдельно сообщением.
   На стикере только визуальная эмоция. Исключение: ранговые значки
   (медаль 🏅 для `first.png`, 🜛 для `prestige.png`) — это символ, не
   текст.
6. **Формат:** PNG-32 с альфой. Дополнительно webp-версия в половину
   размера для загрузки в чате (`<name>.webp`, q=82).
7. **`*.png.import`** генерировать через Godot как для всех ассетов,
   не руками.

## 6. Использование в сообщениях чата — правила

1. **Одно эмодзи в начале строки** для системных сообщений — как на тостах.
2. **В пользовательском чате** эмодзи не ограничивать, но иметь таблицу
   автодополнения на ~80 самых ходовых (взять из секции 1 без
   специальных алхим. значков).
3. **Не смешивать эмодзи и стикеры в одной строке**: стикер всегда
   отдельным блоком/attachments, эмодзи инлайн в тексте.
4. **Цветные символы редкости** (`🜛`, `✦`, `✧`, `❂`, `✺`) всегда
   сопровождаются `[color=...]` BBCode, чтобы не зависеть от шрифта
   (Divagon и Manasco — декоративные, в них эмодзи не рендерятся; эмодзи
   рендерить системным шрифтом через `add_theme_font_override` в
   `ui_style.gd`, отдельный `EmojiFallback` из системы).
5. **Суррогатные пары**: Android и Godot поддерживают emoji-ZWSP-sequences
   (семьи, флаги, составные скины) — в чате разрешить, но в системных
   строках не использовать (разные вендоры рендерят по-разному).
6. **Manrope / Divagon / Manasco не содержат эмодзи-глифов** — это
   нормально. Godot автоматически фоллбечит на системный шрифт
   (`Segoe UI Emoji` на Windows, `Noto Color Emoji` на Linux/Android), но
   стоит явно добавить его как последний в цепочке:

```gdscript
# в ui_style.gd внутри apply_theme:
var emoji_fallback := SystemFont.new()
emoji_fallback.font_names = PackedStringArray([
    "Noto Color Emoji", "Segoe UI Emoji", "Apple Color Emoji", "Android Emoji"
])
th.set_fallback_font(emoji_fallback, "Label")
th.set_fallback_font(emoji_fallback, "RichTextLabel")
th.set_fallback_font(emoji_fallback, "Button")
```

## 7. Порядок ввода (предлагаемый)

1. **Этап 1 (день/два)** — положить таблицу `EMOJI` из §1 в
   `game/data/emoji.gd` (новый autoload или `class_name EmojiMap`),
   подключить fallback-шрифт из §6, заменить все хардкодные `⚡` и `✨` в
   `main.gd` и `online.gd` на `Emoji.ether`/`Emoji.spark`. Тосты из §2
   начать использовать в `_toast()`.
2. **Этап 2** — реакции из §3 на ленте (`_feed_list`): под каждой
   карточкой открытия — ряд из 8 эмодзи-кнопок. На сервере таблица
   `reactions (event_id, device_id, code)`.
3. **Этап 3** — стикеры пака A и B (16 шт.) для диалогов Светика и
   больших поздравлений. Использовать `STICKER_BY_TRIGGER`.
4. **Этап 4** — пак C и D (10 шт.) + бейджи статусов (§5) когда
   доходит до гостевой книги и чата как такового.

## 8. Контрольный чеклист стиля

При добавлении нового эмодзи или стикера проверять:

- [ ] Вписывается в палитру **ночь-бирюза-золото**?
- [ ] Не ломает уютный тон «лаборатория + маленький светлячок»?
- [ ] Эмодзи понятен без слов? (проверить на ком-то, кто не видел игру)
- [ ] Стикер сохраняет канон Светика: каплевидная форма, глаза без рта,
  та же обводка, искры в стиле `charged.png`?
- [ ] Эмодзи не дублирует другой по смыслу?
- [ ] Есть короткий код-строка для сервера (не само юникод-значение)?

`tools/make_stickers_transparent.py` v3 (флудфил по белому фону + дехало белой
антиалиас-каймы + pad 56px → 1024×1024).

### Технические гарантии

- Все 26 PNG 1024×1024, все четыре угловых пикселя строго `(0,0,0,0)` (настоящая
  прозрачность, не шахматка и не белый фон).
- Нет белой внешней ауры/свечения вокруг контура, нет цветной виньетки.
- Тело — один цельный teardrop/pear (острый кончик сверху, гладкий круглый низ),
  без «ножек», без разрывов контура.
- Обводка тёмно-коричневая (~6px), не чёрная.
- Градиент тела `#FFEFD1 (живот) → #E88C3A (край)`, без персикового оттенка.
- Глаза: либо открытые круглые с тёмно-коричневыми зрачками и двумя белыми
  бликами каждый, либо закрытые U-дуги `^_^` в счастливых стикерах; без пустых
  белков без зрачков.
- Рот — только маленький коралловый кружок в радостных стикерах
  (wave/first/gift/celebrate/affinity/daily/cheer/mail).
- Руки (где есть: wave, hi, cheer) — простые flame-нобы того же оранжевого с
  коричневым контуром, без пальцев и жёлтых ладоней.
- Нет текста/букв; sleep-подобные метки выполнены как абстрактные спиральки.
- Туман (mist, offline) — серый/приглушённый, не белый.

### Godot-импорт

`.import`-файлы создаст сам редактор Godot при первом сканировании папки
(UID генерируется движком, их не нужно коммитить заранее). Важно, чтобы в
настройках импорта было включено **`process/fix_alpha_border = true`**
(стоит по умолчанию) — оно убирает остаточную белую кайму на полупрозрачных
краях при рендере в спрайтах.
