## Пайплайн генерации

Ассеты генерируются SVG-скриптом вне репозитория:

```
tmp/contract-board-assets/
├── gen_board.py           Python-генератор 15 SVG (stdlib, без <filter>/<pattern>)
├── svg/                   промежуточные SVG
└── export.gd              Godot-скрипт: SVG → PNG @2x (кроме тайлов @1x)
```

Порядок перегенерации:

```bash
# 1. SVG из генератора
python tmp/contract-board-assets/gen_board.py

# 2. PNG через Godot (ThorVG rasterizer)
Godot_v4.7.2-stable_win64_console.exe --headless \
    --path tmp/contract-board-assets \
    --script tmp/contract-board-assets/export.gd
```

Масштаб: тайлы (board_planks, frame_h, frame_v, shelf_bar) = 1.0, спрайты = 2.0 (@2x).

## Как доска использует ассеты

`game/sigil/contract_board.gd` (Task 9/10):

- **Фон**: `board_planks.png` тайлится в `TextureRect` с `stretch_mode = TILE`
- **Рама**: `frame_h.png` / `frame_v.png` тайлятся по своей оси; `corner_iron.png` — в 4 углах
- **Полка**: `shelf_bar.png` тайлится по X под каждым рядом контрактов
- **Вывеска**: `sign_hang.png` висит на верёвках сверху доски
- **Контракты**: `paper_daily.png` / `paper_weekly.png` — подложка карточки; `paper_note.png` — записка баффа
- **Крепёж**: `nail_brass.png` — гвоздь в каждом углу бумаги
- **Печати**: `seal_{bronze,silver,gold}.png` — на выполненном контракте
- **Штамп**: `stamp_frame.png` — рамка на выполненном контракте (прозрачная середина показывает бумагу)
- **Кольцо**: `ring_pull.png` — кнопка закрытия попапа (дырка в центре)

## Ограничения, которые уже стоили отладки

- ThorVG не поддерживает `<filter>` и `<pattern>` — все эффекты запекаются
  в SVG-примитивах (градиенты, линии, полигоны).
- `stamp_frame.png` — рамка с прозрачным интерьером, а не залитый прямоугольник.
  Тест проверяет непрозрачность рамки по краям, а не центра.
- `ring_pull.png` — кольцо с прозрачной дыркой (through-hole), а не сплошной диск.
  Тест проверяет непрозрачность кольца вдоль горизонтальной полосы через центр.
- Тайлы обязаны быть бесшовными: тест сверяет дельту на шве с внутренней дельтой.
- Бумага — рваный край через альфа-канал, а не нарисованная рамка: 4 угла
  прозрачны, тело непрозрачно.

## Приёмка

Проверки лежат в `tests/suite_contract_board.gd` (§5.2–§5.5):

- §5.2: бесшовность тайлов (seam <= inner * 1.6 + 0.02)
- §5.3: cut-out форма (углы прозрачны, тело/рамка/кольцо непрозрачно)
- §5.3: бумага с градиентом и волокнами (не плоская)
- §5.3: три печати — три разных картинки
- §5.3: гвоздь на мягкой тени (частичная альфа)
- §5.5: все 15 PNG присутствуют вDeclared размерах с .import sidecar
