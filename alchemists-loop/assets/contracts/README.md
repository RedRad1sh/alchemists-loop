## Пайплайн генерации

Ассеты генерируются SVG-скриптом вне репозитория:

```
tmp/contract-board-assets/
├── gen_board.py           Python-генератор SVG (stdlib, без <filter>/<pattern>)
├── svg/                   промежуточные SVG
└── export.gd              Godot-скрипт: SVG → PNG @2x (кроме тайлов @1x)
```

Порядок перегенерации:

```bash
# 1. SVG из генератора
python tmp/contract-board-assets/gen_board.py

# 2. PNG через Godot (ThorVG rasterizer)
Godot_v4.7.2-stable_win64_console.exe --headless \
    --path tmp/contract-board-assets \
    --script tmp/contract-board-assets/export.gd
```

Масштаб: тайлы (board_planks, frame_h, frame_v, shelf_bar) = 1.0, спрайты = 2.0 (@2x).

## Как доска использует ассеты

`game/ui/contract_board.gd` и `game/ui/contract_card.gd`; часть ассетов
переиспользует обмен картами (`game/social/trade_ui.gd`).

- **Фон доски**: живой фон — рамка `kit_01b/17_contract_board_frame.png`;
  `board_planks.png`, `frame_h.png` / `frame_v.png`, `corner_iron.png`,
  `shelf_bar.png`, `sign_hang.png`, `board_vignette.png` — тайлы и декор рамы.
- **Записки баффов**: `board_note.png` — подложка записки на доске;
  `paper_note.png` — бумага записок и офферов обмена.
- **Строка ранга**: `plate_brass.png` — латунная плашка; `paper_strip.png` —
  бумажная полоса вех.
- **Печати**: `seal_{bronze,silver,gold}.png` — сургуч по тиру контракта.
- **Штамп**: `stamp_frame.png` — рамка на выполненном контракте (прозрачная
  середина показывает бумагу).
- **Крепёж**: `nail_brass.png` (+ варианты `_b/_c/_d`) — гвоздь записки.
- **Кольцо**: `ring_pull.png` — кнопка закрытия (дырка в центре).
- **Награда**: `popup_scrim.png` — затемнение; `reward_letter.png` — письмо.
- **Бумага контрактов**: `paper_daily.png` (+ `_b/_c`), `paper_weekly.png` —
  силуэты дневной и недельной записки (рваный край через альфу).

## Ограничения, которые уже стоили отладки

- ThorVG не поддерживает `<filter>` и `<pattern>` — все эффекты запекаются
  в SVG-примитивах (градиенты, линии, полигоны).
- `stamp_frame.png` — рамка с прозрачным интерьером, а не залитый прямоугольник.
  Тест проверяет непрозрачность рамки по краям, а не центра.
- `ring_pull.png` — кольцо с прозрачной дыркой (through-hole), а не сплошной диск.
  Тест проверяет непрозрачность кольца и наличие прозрачной дырки.
- `corner_iron.png` — уголок-«Г»: непрозрачны только верхняя и левая кромки,
  тело прозрачно. В общий список бумаг не входит (там тело обязано быть
  непрозрачным по центру); для него отдельная проверка.
- Тайлы обязаны быть бесшовными: тест сверяет дельту на шве с внутренней дельтой.
- Бумага — рваный край через альфа-канал, а не нарисованная рамка: 4 угла
  прозрачны, тело непрозрачно.

## Приёмка

Проверки лежат в `tests/suite_contract_board.gd` (§5.2–§5.5):

- §5.2: бесшовность тайлов (seam <= inner * 1.6 + 0.02)
- §5.3: cut-out форма (углы прозрачны, тело/рамка/кольцо непрозрачно)
- §5.3: уголок-«Г» с прозрачным телом (отдельная проверка)
- §5.3: бумага с градиентом и волокнами (не плоская)
- §5.3: три печати — три разных картинки
- §5.3: гвоздь на мягкой тени (частичная альфа)
- §5.5: все 26 PNG присутствуют в заявленных размерах с .import sidecar
